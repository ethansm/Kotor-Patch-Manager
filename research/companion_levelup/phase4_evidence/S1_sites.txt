## Callee facts (C)
- CanLevelUp 0x6B9790: thiscall(ECX = stats), NO stack args, plain `RET` (c3) (S1_raw_sites_disasm.txt, 6B9790..6B9863; prologue 55 8B EC 83 EC 20 56). Returns EAX 0/1.
  It reads stats+0x24 (creature POINTER: `mov edx,[ecx+0x24]` at 0x6B97F4, then calls vtable [creature]+0x94 and reads creature+0x11AC at 0x6B981D).
  => stats+0x24 is a POINTER to the creature (NOT an embedded offset). Reverse link: creature+0x1198 holds the stats pointer (every site below loads ECX from `[creature+0x1198]`).
  Tag: *(char**)(*(stats+0x24) + 0x18) with len at +0x1C (CExoString) - exactly LevelUpOverride.cpp readTag (St_Creature=0x24, Cr_Tag=0x18). Proven there for server creatures (LevelUp hook);
  for the CLIENT creatures used at 0x74F3C7 / 0x84F221 / 0x756B70 / 0x752050 the same stats+0x24 -> creature link is used by CanLevelUp itself, but the +0x18 tag layout on the client class is I (SafeRead + log-only check first).
- Options accessor 0x72FB00: `__fastcall`/thiscall ECX = [0xA1B4A4]+4 (client app), body: mov ecx,[ecx+4]; mov edx,[ecx+4] ... returns EAX = options object; NO stack args (all 4 sites push nothing before the call). RET form: ends after 0x72FB10 (c3, DB/doc: `return *(*(this+4)+4)`), I: plain RET (disasm shows no `ret N` fragment in the 0x72FB00..0x72FB10 window; prior evidence calls it __fastcall with ~264 callers).

 (b) no push before any of them; callee RET plain. (c) post-call register use: EAX only (`test eax,eax`/`mov [..],eax`); every later ECX/EDX is reloaded from the frame -> no compiler-bug dependence on ECX/EDX. (e) no toml hook within +-16 bytes anywhere (S1_raw_overlap_scan.txt; 413 unique hooks from 77 files = repo *_src tomls + Patches/*/; nearest owner listed per site).

## B. Options accessor 0x72FB00 call sites (R4 instant levelling). All `E8 rel32`, ECX = [A1B4A4]+4 spilled, no stack args, live == vanilla, no toml hook within +-16.
 Handler contract: `void* acc(ecx)`: real = 0x72FB00(ecx); if the creature in the frame slot is opted-in -> return pointer to a fake 12-byte block {?, ?, +8 = real[+8] | 1} (copy the real object's first 0x10 bytes or make a stable static whose +8 = 1) else return real.
 Reads of the returned pointer: ONLY `[ptr+8] & 1` (S1_raw_sites_disasm.txt; for 0x74F3E9 the spilled slot [ebp-0xF0] is read once at 0x74F3F4->0x74F3FA; the other three slots ([ebp-0x98] 0x5FD7A5, [ebp-0x50] 0x5FE286, [ebp-0x60] 0x66C93F) are read once immediately - grep of the whole functions in D1_disasm_xp_gates.txt shows no later read of those slots (the 0xFFFFFF10-family slot at 0x74F3EE is read only at 0x74F3F4)). EAX dies right after the `mov [slot],eax`.
