# B5 - what "Pause at level minPause" gains and loses vs the preset default

Generated by `phase6_evidence/B5_pause_tradeoffs.py` (re-run: `cd research/companion_levelup && ../../.venv/bin/python3 phase6_evidence/B5_pause_tradeoffs.py`). Presets are the CURRENT ones (B4 fixes of 2026-10-03). Decisions come from `simulate_rewrite.level_now` (Python twin of the C++ `levelNow`, proven equal in B2/parity), the same engine loop as `B2_rebase_check.py`.

## How to read this
- **Default** = the preset's own rule: take the base-class records up to `convert_at - 1`, bank, the story script adds the Jedi class, every banked level is then a Jedi level (REBASE onto the preset's Jedi records).
- **Pause at minPause** = freeze at `minPause` (the preset's first level-up minus 1, i.e. the level the companion already has when you recruit him/her), bank every later level until the Jedi class exists, then the same REBASE. The Jedi class arrives at a STORY point, not at a level (see each companion), so the freeze lasts until that story point; the end state is char level 30 in both columns.
- Both paths end at character level 30 with exactly two classes. Pausing early swaps the base-class levels in `minPause+1 .. convert_at-1` for extra Jedi levels at the END of the Jedi record list (Jedi class level 1 is taken at char minPause+1 instead of at convert_at).
- Jedi records only exist up to class level 30-convert_at+1; when the pause path has more Jedi levels than records, the surplus levels are **unplanned** (`VANILLA`: the engine's own picks / the player chooses in the GUI).
- **BAB**: identical in every path. `classes.2da` (offline snapshot `replay/scratch/override/classes.2da`) points ALL of Soldier, Scout, Scoundrel, Tech Specialist, Guardian, Consular and Sentinel at `CLS_ATK_1`, so base attack bonus depends only on character level (the "Sentinel 0.75/level" note in atton.md is not what the 2DA says).
- **Saves**: classes use different tables (`CLS_ST_*`: Soldier/Scout/Scoundrel/TechSpec vs JEDI_G/C/S); the table contents live in BIFs and are not in the offline snapshot, so no save numbers are computed here (open item; check in game).
- **Force/VP**: nominal die per class level from `classes.2da` (forcedie Guardian 4, Consular 8, Sentinel 6, base classes 0; hitdie Soldier 10, Scout 8, Scoundrel 6, TechSpec 6, Guardian 10, Consular 6, Sentinel 8). Force points = die x extra Jedi levels (plus Wisdom bonus; how the engine rolls the die was not checked). Skill points per level are `skillpointbase` + INT mod (Soldier 1, Scout 3, Scoundrel 4, TechSpec 4, Guardian 1, Consular 2, Sentinel 3).
