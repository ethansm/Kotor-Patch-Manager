# H11 recon: holster-editor English item names and scope labels

## 1. Where the name text comes from
- Hand buttons: `HolsterEditor.cpp:1032-1037` call `readWeaponModel(regGob[h])`, then set `"Right: %s"` / `"Left: %s"`.
- `readWeaponModel` (`HolsterEditor.cpp:391-405`) reads gob+0x84 -> model+0x08, 16 chars max. That is the MDL resref (w_blstr_01).
- Status line `HolsterEditor.cpp:463` uses `editInfo.model`, which is the same gob name (`holster_src/Holster.cpp:641`).
- `K2HolsterEditInfo.type` = `categoryName()` (`Holster.cpp:951`): lightsaber, melee, qstaff, pistol, rifle, heavy, unknown.
- Member name (NAME button) = `hse::memberName` (`HseParty.h:23-70`), creature stats LocString. Not an item.

## 2. Reachable item name (no new engine addresses)
- Item id per hand: creature +0x238 (right), +0x23C (left) (`preview_3d_src/Preview3dProvider.cpp:60,263-272`). `NoItemId` = 0x7f000000.
- Item object: `getItemObj(id)` = `ClientGetItemById(*(*AppGlobal+4), id)` (`Preview3dProvider.cpp:187-190`; `GameAddr.h:119`).
- Item name: CExoLocString at item+0x2C0, read via `GetLocString` (`GameAddr.h:99`), language from `GetClientLanguage` (`GameAddr.h:100`). Same pattern as `HseParty.h:47-70`.
- Reference reader: `inventory_sort_filter_src/InventorySortFilter.cpp:151-170` (`readItemName`). It takes `app` from GuiGlobal. The holster editor should use the HseParty chain (AppGlobal -> +4) instead.
- Preview3dApi exposes only the gob, not the item. The holster provider sees the item only at the attach sites (`Holster.cpp:447`, `[ebp-0x40]`/`[ebp-0x30]`).
- Gotcha: `i_null` / empty model = no weapon (`Preview3dProvider.cpp:248-256`). Only look up names when regGob is non-null.

## 3. Button geometry and font
- Strip = `leftStrip(COLUMN pane, VIEW pane, gap 6)` (`HolsterEditor.cpp:599-601`). Its width is runtime; repo docs do not record it. The `LAYOUT strip=(...)` probe line prints it.
- Full-width rows: name, scope, bone, stance, emote, play (`stripSlot`).
- Half-width buttons: Right/Left, Save/Revert, Reset/Done (`half(..., 6)`), so budget = (strip.w - 6) / 2 px.
- Font: MUI button font is not confirmed. `TextFit.h` (`textPx`, `fitText`) uses 2.0 px per texel at the 1600 px reference (TextK 0.75 x 8/3). Treat as an estimate.
- Texel widths (dialogfont16x16, `FontWidths.inc`): "Right: " 63, "Right: None" 105, "Right: w_blstr_01" 164, "Scope: Weapon" 134, "Scope: Category" 151.
- "Right: " alone takes ~63 texels (~126 px). The prefix eats most of a half button.

## 4. Proposal
Scope button (full width, cycles Weapon -> Category -> Body):
- "For: this weapon" (159 tx), "For: all rifles" (139), "For: this body" (135). Put the full meaning in the tooltip via `SetDesc`: "Applies to: this weapon only / every weapon of this type / every weapon on this body".
- Hide Category when type is `unknown`. `HolsterPreview.h:258-260` already refuses that scope.

Type plural map (`type[12]` -> label):
- lightsaber -> "all lightsabers"; melee -> "all melee weapons"; qstaff -> "all quarterstaves"
- pistol -> "all pistols"; rifle -> "all rifles"; heavy -> "all heavy weapons"; unknown -> hide

Hand buttons (half width):
- Label = item name only (drop "Right: "), e.g. "Blaster Pistol" (137 tx). Cut with `textfit::fitText(maxPx = (strip.w-6)/2)`, which adds "...".
- Tooltip via `SetDesc`: "Right hand: <full name> (<model>). Click to edit holster placement."
- Fallback when no name: keep "Right: Equipped" / "Right: None".

Implementation sketch:
- Refactor `HseParty.h` GetLocString block into `locString(handle, out, cap)`.
- Add `hse::handItemName(creature, hand, out, cap)` (+0x238/+0x23C, ClientGetItemById, +0x2C0).
- Use it in `HolsterEditor.cpp:1032-1037` and `setHandNames` (line 435).
- Host test in `hse_view_test.cpp` for the label formatter (fit and fallback).
