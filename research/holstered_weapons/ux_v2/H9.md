## Already covered
- Preview uses the live appearance of the bound party member (body, gender via model name) on every open.
- Per-body offset delta gives N_CommM and N_CommF separate tuning.
- Hilt length per saber type (HolsterLogic.h:155) centres the hilt on the mount.

## Real gaps
1. E: no HILT ONLY / EXTENDED view and no blade-state fact. Q7 gates this. Hiding a blade needs an engine-side node hide, not built.
2. G-armour: armour bulk in the preview is unverified (claim 7). Editor-open rebuild covers "current armour" only if claim 7 holds.
3. G-cycler: no mannequin or body cycler. A delta tuned on one body is never checked on another, and the body delta moves offset only.
4. G-scale: modelscale has no code path (claim 9). Offset portability across scaled bodies is untested (claim 10).
