# H5: holster-editor mouse gestures and RMB+LMB chord
Src: holster_editor_src/HolsterEditor.cpp (cbTick 658-1000), HseView.h, _shared_src/GuiKit.h, ViewDrag.h

## 1. Gesture map (current)
Per tick: wheel 851-864, then read lmb/rmb/mmb 866-868, mouse 870-993, state machine 996+.
- Wheel, no Shift (NAV and WEAPON): zoom, 860-862.
- Wheel + Shift (WEAPON): depth, NudgeWorld dp[0]=-step (0.02, Ctrl 0.05), 854-858.
- LMB drag in view (NAV): p3d::dragMove, axis-locked yaw OR pan (lockPx 4), 972-993; cfg 283-287.
- LMB drag in view (WEAPON): NudgeWorld dp{0,dx,-dy}*0.0025/zoom; Shift x0.2 (910); Ctrl 1 cm snapAccum (912-916); 894-929.
- RMB drag in view (WEAPON): trackball NudgeWorld dq, 0.5 deg/px, Shift x0.2 (945), Ctrl per-tick round to 5 deg (948); 931-962.
- RMB in NAV: no handler.
- MMB drag (WEAPON): yaw spin 0.5 deg/px, 872-891. MMB click (NAV): reset view, 965-972.
- Buttons: engine ui->Clicked, not polled, 674-826. Early returns at 678, 688, 695 skip the mouse section.

## 2. Input path
- Buttons and modifiers are GetAsyncKeyState via g_gk hooks (GuiKit.h 694-707). Polled; edges are prev-tick flags.
- Focus: fg = g_gk.gameForeground (GuiKit 687-692). Not foreground forces lmb/rmb/mmb/shift/ctrl false (866-868).
- Wheel: WheelHook (GuiKit 495-575; k2input cb 627-647). Consumed only inside the view rect (set 607, cleared 617). freshMs 300 needs touch each tick. dragGuard unset, so wheel is eaten while RMB is held.
- Engine conflict: none found on the mod side. Engine GUI-class RMB is axis action 0x1A (27_companion_selfheal_evidence/R6_rmb/dump/007b12c0.c:359-372), a cutscene skip gated on in-game objects. Options path untested (R6 caveat). Camera hold flag DAT_00A7FCBC is in-game class only.
- Reverse Mouse Buttons rewrites WM_RBUTTONDOWN only; polling is physical, so unaffected.

## 3. Defects in current code (fix in the same change)
- Shared lastMouseX/Y: LMB writes it at 920 before RMB reads it at 941. While LMB moves, RMB rotation gets dx=dy=0.
- enterEdit/exitEdit (541-590) never reset pressed, draggingLmb/Rmb/Mmb, pressedRmb, or e.drag. Only cbLeave (624-630) does.
- RMB Ctrl snap rounds per tick with no carry (948); LMB uses snapAccum (912). Slow rotation is biased.

## 4. Host-testable home
HseView.h has pure snapAccum (139), guardArmLive (147), guardProceed (152). ViewDrag.h has p3d::Drag and view_drag_test.cpp. Propose a pure `hse::Chord` step in HseView.h (inputs L,R,edges,inView,fg,shift,ctrl,dxy,wheel; outputs orbit/move/rot/depth/spin), tested in hse_view_test.cpp.

## 5. Proposed state table (WEAPON; read R before the wheel branch)
| State | Event this tick | Next | Action |
|---|---|---|---|
| IDLE | Ledge, inView, !R | ORBIT | p3d dragBegin (NAV path reused) |
| IDLE | Ledge, inView, R held | MOVE | last=cursor, zero snapAcc |
| IDLE | Redge, inView, !L | ROT or none (OPEN) | last=cursor |
| IDLE | Redge while L held | DEAD | no gesture |
| ORBIT | Redge | ORBIT | ignore RMB until L up (latch) |
| ORBIT or MOVE | !L or !fg | IDLE | dragEnd / zero snapAcc |
| MOVE | dx or dy | MOVE | NudgeWorld dp{0,dx,-dy}*k |
| MOVE | !R, L held | DEAD | stop move, no orbit until L up |
| DEAD | !L | IDLE | none |
| any | wheel, R held | same | depth step; wheel consumed |
| any | wheel, no R, no Shift | same | zoom (existing) |
| any | enter/exit edit, cbLeave, not-ok tick | IDLE | reset all flags, dragEnd |
Gemini Shift+RMB tilt collides with today's Shift slow-rotate (945).

## 6. Edge cases (recommended handling)
1. RMB after LMB orbit: latch, ignore until L up. Alt: switch to MOVE.
2. LMB released before RMB: MOVE ends; RMB alone per OPEN.
3. RMB released mid-move with L held: DEAD, no orbit jump.
4. LMB pressed outside view with RMB held: no gesture (894, 931 rule).
5. RMB pressed outside view, LMB in view: require RMB edge in view (931-935).
6. Same-tick edges: read R before deciding L, so MOVE wins.
7. Alt-tab mid-drag: !fg takes release path. On return, a still-held button needs a fresh edge.
8. Shift toggled mid-drag: speed only, no jump.
9. Ctrl toggled mid-drag: use snapAccum for RMB too (948).
10. Discard guard (678, 688, 764-821) returns early and skips mouse; cancel gestures on refusal.
11. Done/Save with RMB held runs exitEdit with stale flags (defect 2).
12. Wheel and RMB same tick: move the R read above take() at 852.
13. Early return (665) or member switch (685, 695) mid-chord: reset on resume to avoid a first-frame jump.
14. Freeze anim while RMB held (Gemini): optional; PlayAnim(token,"pause1") exists.
