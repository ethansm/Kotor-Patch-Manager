## Q1 composition order
Holster.cpp does not compose; it calls hs::applyPlacement. Off is in bone (node) frame, applied first. Rot is applied last as q = node.q * qbase(rot), so pivot = node*T(off). Matches C.

## Q2 storage, quat, unwrap, lock
- Stored rot = Euler deg in TuneCfg, saved %.1f (HolsterTune.h:432). Off saved %.3f.
- Internal quat = EditOverlay.placeQ. overlaySync (HolsterPreview.h:118-122) re-derives Euler each GetEdit via eulerNear(placeQ, prev = last shown rot).
- "Unwrap" = nearest of two equivalent triples {rx,ry,rz}, {rx+180,180-ry,rz+180}, wrapped (HolsterEdit.h:106-108). Not an accumulating unwrap.
- Band 80 <= abs(ry): rx frozen to wrap180(prev[0]), rz solved by Procrustes (HolsterEdit.h:88-104). Exact only if prev[0] = true rx.
