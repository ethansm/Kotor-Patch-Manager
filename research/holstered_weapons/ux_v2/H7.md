## 4. Freeze / slow-mo feasibility
- preview-3d API (Preview3dApi.h:83): PlayAnim(token, anim) only. No speed, pause, seek or time slot. RigGob (:85) returns body/head Gob for raw vtable calls.
- Speed arg is NOT a rate: decompile stores `local_14[1] = (int)param_3` (R4a:169). Fractions truncate to 0; sign picks loop sentinel (R4a:156) or clip length. Slow-mo via speed is REFUTED (per-tick consumer not read).
- Seek is possible: start arg wraps modulo clip length (R4a:129-133). Scrubber needs a start-time slot added to the API (not present today).
- Flag 0x400 on a playing anim sets bits 0x400|0x1 in its flag word (R4a:106). Possible freeze lead; consumer unknown, UNVERIFIED.
- NULL or empty name stops all anims (R4a:77). That leaves a bind pose, not a freeze.
- World clock dt has a scale factor (V5 3a). It is global, so it slows the whole world, not the preview.
- Freeze/slow-mo: UNSURE. Needs one live probe (flag 0x400 hold, re-issued start time).
