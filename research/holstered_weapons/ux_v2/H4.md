## Mirror formula (bone frame: x right, y forward, z up; sagittal plane x=0)
- Right: R = Rz(rz)*Ry(ry)*Rx(rx) (qbase, HolsterQuat.h:36-39), X applied first. off = (x,y,z).
- M = diag(-1,1,1). Left: R_L = M*R*M, off_L = M*off.
- Result: rot_L = (rx, -ry, -rz); off_L = (-x, y, z). Same for any euler order, since M conjugates each axis rotation.
- Check (python, stdlib): max |M*R*M - R(rx,-ry,-rz)| = 0 over 2000 random angles.
- Exact for torsoUpr_g: identity rotation, origin x=0 (back_dblsaber.md:5).
- Caveat: the mesh is not reflected. Left = rigid rotation of the mesh, equal to a true mirror only if the weapon is mirror-symmetric in the plane R maps to x=0.

## left_extra_rot composition (bone-frame tilt, after the mirror)
- R_L' = Rx(ex)*R_L (outer). Quaternion: qmul(qaxis(X,ex), qbase(rot_L)), then eulerFromQ (HolsterEdit.h:65).
- Do not add ex to rot_L[0]: euler components do not sum like rotations.
- Sign: ex < 0 moves the left barrel away from the back (-y). ex = -8 gives crossing y -0.160; ex = +8 gives -0.102, inside the back (surface -0.116, back_dblsaber.md:6).

## Why left overlaps today (static, not log-verified)
- effLeft(left) = left && g_boneLeft (Holster.cpp:631-633). Editor preview and scope use it (Holster.cpp:666, 894, 1009). With bone_test_left=0, a left weapon resolves as right: no mirror, same offset, overlap.
- In-world HolsterPlace does not use effLeft: left comes from the hand ring (Holster.cpp:743, 761). It needs only bone_test. In-world overlap cause is not decided by code.
- bone_test_left also gates the lhand attach repoint (Holster.cpp:1135).
- Repo holster.ini: bone_test=0, bone_test_left=1 (lines 25-26). Live values not in repo.
