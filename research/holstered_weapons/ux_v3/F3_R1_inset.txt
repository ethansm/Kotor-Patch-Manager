3. WORKED EXAMPLE

Setup: button rect r = (0, 0, 200, 34). Normal case: X+0 == 0, corner width G = c > 0,
so both B and H take the uniform path (a = b = s = c). Assume M = T = 0 (margin fields NOT verified).
  x: iw = 200 - 2c ; xi = c ; wi = 200 - 2c            (qx != 0 for c <= 200-2c)
  y: ih = 34 - 2c  ; if ih < c/2 -> yi = 17, hi = 0    (zero-height branch)
                    else          -> yi = c,  hi = 34-2c
  Intersect(inB, inH): both identical here, so caption = (c, c, 200-2c, 34-2c)
                                                       unless the zero-height branch fires.

  c = 4  -> caption (4, 4, 192, 26)
  c = 8  -> caption (8, 8, 184, 18)
  c = 16 -> caption (16, 17, 168, 0)     ih = 2 < 8 -> zero height at y=17
  c = 20 -> caption (20, 17, 160, 0)     ih = -6 -> zero height

With M > 0 (unverified): out.x = c - min(M,c), out.w = (200-2c) + 2*min(M,c); y/h use T fully.
Corner width c is the only input that matters in the normal path. Edge size e is NOT used
unless c = 0 (fallback path, divisor = Q.vt[+0x10]).
Fallback c = 0: caption = (a, b, 200-2a, 34-2b) with a = A.vt[+0x10](), b = A.vt[+0xc](),
  thresholds on divisor s = Q.vt[+0x10](), and no x-margin (mG = 0).
Null pointers with G = 0: a = b = s = 0, inner = (O.x, O.y - T, O.w, O.h + 2T): full rect, not zero.

======================================================================
4. NOTES AND QUIRKS
======================================================================
- x uses min(M,G) (margin capped at corner width); y uses T uncapped. Asymmetric. dc:91-103.
- The fallback path (G = 0) gives mG = 0, so O+0x18 has no effect there.
- Discarded call at dc:33 (Q.vt[+0xc]) may have side effects.
- Intersect is not clamped; a disjoint H/B produces negative w/h passed to T.vt[1].
- FUN_00417800 is called with ECX not shown by the decompiler; ECX=obj assumed (not checked in asm).
- name_map.tsv:79 "GetDimension returns [border+0x14] if non-zero else corner image width" matches the asm.
- name_map.tsv:84 GetInnerExtent, name_map.tsv:117 SetExtent: names consistent with the code.
