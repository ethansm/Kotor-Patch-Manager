1. Resize: guikit::setRect -> view vtable 0x9A3D34 slot +4 = 0x420F50 (_shared_src/GuiKit.h:244-247). It forwards the rect to CSWGuiScene (view+0x60) slot +4 = 0x414B70 (plain 4-int copy), then stores view+4..+0x10. Anchors: D/42/00420f50.c:6-10; D/41/00414b70.c:6-9.
2. Draw: view slot +0x38 = 0x84DE40 -> CSWGuiScene vtable 0x98771C slot +0x0C = 0x4184F0. Anchors: D/84/0084de40.c:6; D/41/004184f0.c:8.
3. 0x4184F0 passes the live rect (scene+4..+0x10 = x,y,w,h) to 0x479460, which calls glViewport(x, rootH - y - h, w, h). rootH = DAT_00a309ce (root record height, presumably screen height). 0x479460 returns 0 when w<1, h<1 or off-screen, and then no camera draw runs. Anchors: D/41/004184f0.c:9-12; D/47/00479460.c:56.
4. 0x4184F0 then calls camera (view+0x78) slot +8 = 0x47F320. Anchor: D/41/004184f0.c:13.
5. 0x47F320 with camera +0x220 and +0x224 both zero queries GL_VIEWPORT (0xBA2), sets aspect = that w/h, then gluPerspective(fovy, aspect, near, far). Anchors: D/47/0047f320.c:115-118, 188.
6. So in the default state the projection follows the control rect every draw. Nothing is cached in the camera.
