5. Answer to Q2: [owner+0x138] as in-combat flag
- COMB reads [creature+0x138] as old state (Holster.cpp:321-325). Steam offset 0x138 (K2Addr.h:400). If owner == creature, COMB reads [owner+0x138].
- Setter 0x7682B0 = thiscall(creature, newState), stores this+0x138, returns old (GameAddr.h:75; K2Addr.h:199, 206).
- Holster code calls it the "client combat flag"; nonzero vs 0 is the edge (HolsterLogic.h:6, 193). G2 VERIFIED enter/exit for PC and NPC. The 1=in-combat reading is inferred from that, not stated in code.
- HolsterPlace never reads [owner+0x138]; it reads only [parent+0x1D8]. GOG offset is 0 (inert, K2Addr.h:587).
