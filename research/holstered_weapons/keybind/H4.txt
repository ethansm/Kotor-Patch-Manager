=== Verdict for the detour ===
  Mechanically viable. 9-byte prologue window, boundary-aligned, no relative branches, no jumps into it, no other patch on it.
  The handler can read or write memory before the body, so a write to +0x524 or +0x528 would take effect in the same AIUpdate pass (before the countdown at decomp lines 148-152).
  Cost: fires for every creature in every level list each pass, so filter first.
  S1 plan (b) (tick-side write of +0x524 with the PC server pointer) needs no detour. Use the detour only if the same-pass write is needed.
