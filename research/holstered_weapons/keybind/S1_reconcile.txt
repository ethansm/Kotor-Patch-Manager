(2) Polling an arbitrary action id (V, asm 0x7AE862-0x7AE871):
  push slot ; push id ; mov ecx,[0x00A1B48C] ; call 0x0072F9D0 ; fstp float
  - 0x72F9D0 = thiscall(ECX=W, id, slot) RET 8, W=[0xA1B48C] (written at startup in 0x409750). It forwards ECX=[W+4] (the input manager) to 0x72C320(id, slot) and returns a float in ST0 (V, asm 0x72F9D0-0x72F9ED).
  - 0x72C320 (V): requires 0<=slot<6; requires 0x72B3E0(id,slot) != 0 (bit id in bitmask [mgr+0x3C+slot*0x40]); entry = table[id] ([mgr+0x188+id*4], count [mgr+0x18C]); switch(entry+0x14): types 0,2,5 -> held value from 0x72C010; type 1 -> returns 0 ALWAYS; type 3/4 -> axis.
  - Works for an id that no engine switch knows, with three conditions (all V from code):
    a) table[id] exists: created by 0x72B4D0 in the loader (part 2) for ids 200..269 whose 2DA row is not Disabled and which have a key (ini or 2DA). The array grows on demand (0x840EF0), no cap issue.
    b) entry type must be 0, i.e. the 2DA row needs EventType=1 (as shipped action268 WALKMODIFY). EventType 0 (default) -> type 1 -> poll returns 0. Event-style rows are delivered by the event queue path (0x72C7E0), not by this poll.
    c) the context bit must be set: 0x72B830(id, ctx) sets it only if the key is 0x86 (unbound) or 0x72B300(key,device,ctx)==0 (G: no other action already bound to that key in that context) and not already set.   - Calling convention for a mod: __thiscall with 2 stack args, callee pops 8, float result in ST0 (declare as __fastcall-with-dummy-edx or use inline asm/naked thunk; MSVC thiscall typedef + float return works because ST0 is the standard x87 float return).
