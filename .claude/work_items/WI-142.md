## Goal
CQ-QS1 fact 7: Kreia ran GN_DetermineCombatRound (DCR) 2-3 times per engine round end, the runs 20-40 ms apart; each run does ClearAllActions + a new cast, so each one appends a round node (stale-build backlog). A party member (not the leader) now runs DCR at most once per 0.15 s window; the duplicate run returns at once with a trace line. Window 0.15 s stays below the vanilla delayed re-calls (0.2 s non-party only, 0.3 s a_atkonend, 3.0 s retries). A skip counter self-heals a stuck flag (save/load inside the window): after 3 skips in a row the run goes ahead.
