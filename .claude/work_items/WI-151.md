## Goal
When the New, Usable or Upgradeable filter matches nothing, the backpack list is blank with no feedback. The LBL_FILTER caption (captionOf, SortLogic.h:74) is the one text surface the mod already writes. Show the visible count there for filtered states: "Filter: Usable (12)", "Filter: Upgradeable (0)". "Filter" (All) stays unchanged.
## Steps
1. SortLogic.h: `inline void captionWithCount(State s, int rows, char* out, int cap)`: All -> "Filter"; other states -> `"%s (%d)"` from captionOf. Keep it under the 24-byte g_caption (InventorySortFilter.cpp:185): raise g_caption to 32 and the helper's cap check to match.
2. sort_logic_test.cpp: All with 5 -> "Filter"; Usable with 0 -> "Filter: Usable (0)"; Upgradeable with 123 -> "Filter: Upgradeable (123)"; a cap too small truncates safely and stays NUL-terminated.
3. InventorySortFilter.cpp SortFilterFlush (:381): after the buffer is final (rows = g_n), when cycle is on and stateOf(mode, g_extra) is a non-All state, call captionTo(panel, captionWithCount(...)). The engine's New mode (1) filters before our hook, so g_n is the visible count there too.
4. normaliseState (:265) re-applies the plain caption at populate start; the count replaces it at flush in the same frame, so there is no visible flicker. Note this in a comment.
