Controller bumpers change the filter through the engine's SetNextFilter 0x8A8B30 directly, bypassing the tab-click hook H6a. normaliseState (InventorySortFilter.cpp:261-267) then resets our extra filter, so controller players can reach New (engine mode 1) but never Usable or Upgradeable.

2. Design (owner): treat our states as virtual modes after New in the bumper order (All -> New -> Usable -> Upgradeable -> weapons ...), or bind them to a separate button.
3. Build: a detour on the bumper's SetNextFilter call site that maps the computed next mode through a pure `isf::bumperNext(mode, extra, dir, mask)`, with tests both ways (left and right bumper) in sort_logic_test.cpp.
4. Validate the new window with check_windows.py, and add the hook to kotor2-steam-aspyr.hooks.toml with original_bytes.
