## Goal
`loadIni(false)` (InventorySortFilter.cpp:119) runs from the tab-click and buffer-row hooks. At most once a second it makes 6 GetPrivateProfile* calls, and each one opens and parses the file (slow under Wine). Skip the re-read when the file's last-write time is unchanged.
## Steps
1. Add `FILETIME g_iniWrite = {}` next to `g_lastIni` (:116).
2. In loadIni, after the 1-second throttle: `WIN32_FILE_ATTRIBUTE_DATA fa; if (!force && GetFileAttributesExA(IniName, GetFileExInfoStandard, &fa) && CompareFileTime(&fa.ftLastWriteTime, &g_iniWrite) == 0) return;`, then store the new time before reading. If GetFileAttributesExA fails (file missing), fall through to the current read (defaults), but only when the previous state was "present", so a missing file is not re-read every second either.
3. Keep the `force` path in DllMain (:441) unconditional.
