Task: verify one claim about one source file.

Decide whether the claim is supported by the excerpt alone. Use only the claim, the file location, and the numbered excerpt below. If the excerpt does not contain enough information to decide, say so in the output instead of guessing.

Work through it this way:
1. Restate the claim in your own words in claim_restated.
2. Find the lines in the excerpt that bear on the claim. Put lines that support the claim in supporting_quotes, and lines that contradict it in refutation_quotes. For each quote, give the file path, the line number shown in the excerpt, and the line text copied character for character. The text field holds only the line content, without the line number prefix.
3. Choose the verdict from the enum values in the attached schema, based only on what the excerpt shows.
4. Set confidence to high, medium, or low.
5. In not_verifiable_without_running, state what could not be checked from the excerpt alone. In residual_questions, list open questions. Use an empty list or an empty string when there are none.
6. In counter_evidence_searched, record each search you made inside the excerpt, with the pattern, the scope, the number of hits, and a note. Use an empty list if you made no search.
7. In tool_trace, record any tool use. Use an empty list if you used no tools.
8. Set finding_id to the string UNSCORED. No ids are supplied for this prompt.

Output only one JSON object that matches the attached schema. Do not write any text before or after the JSON, and do not wrap it in a code fence.
