Answers:
- Q1: 36/40 Wilson [0.769, 0.960]. 5% of 40 is 2 units. Not meaningful: a 2-unit sample cannot separate 90% from 50%.
- Q2: Correlated errors are supported by the data. Both pipelines fail the same 4 of 12 parents (ladder_experiment.md:25). Style-level totals only (:28-29). Measured extra-layer results: 8/12 both; judge picked an accepted variant in 6/6 parents where one existed (:30-31); 2 revise parents stuck after 3 rounds; rescue bought 0 accepts. Note: the 2-vs-3 Haiku layer question has no measurement on disk; the only ladder result is .claude/reviews/ladder_experiment.md. The .claude/review/fix/results and judge directories hold per-parent JSON, not a separate ladder summary.
- Q3: 13/40 Wilson [0.201, 0.480]; exact [0.186, 0.491]. A calibration threshold is not meaningful at n=40: each decoy is 2.5 pts, and the interval spans 29 pts.
- Q4: Key must include resolved model id (alias "haiku" is used at ~/.claude/settings.json:2 and engine/dr.py:568), CLI version (2.1.296 here), effort (CLAUDE_CODE_EFFORT_LEVEL overrides, design_draft.md:20), tools, permission mode, settings sha, budget, prompt and schema sha, and input file shas. A content-addressed cache is not safe across an alias move without the resolved id.
- Q5: Paired run of 2-layer vs 3-layer on the same labelled units; McNemar-style discordance count. Formula: n = (z_{a/2} sqrt(phi) + z_b sqrt(phi - d^2))^2 / d^2, alpha 0.05 two-sided, power 0.8, d = 0.10. phi = 0.10 gives 77 units; phi = 0.20 gives 155 (computed). Unpaired fallback n per arm = (z_{a/2} sqrt(2 pbar qbar) + z_b sqrt(p1 q1 + p2 q2))^2 / d^2: 80% to 90% gives 199 per arm; 50% to 60% gives 388 per arm (computed). Minimum target: 155 paired labelled units, ground truth from seeded bugs and decoys, not Haiku judgment.
