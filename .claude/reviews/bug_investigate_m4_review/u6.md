# U6 quote-validity gate edge-case review

Probe: out/u6_probe.py run with python3 -I against synthetic bundles with valid hashes.

## Missed edge cases (severity H/M/L, file:line, scenario, fix)
1. H scripts/bug_investigate.py:478 (rank_key) with evidence_quote_check.py:156-157. Ranking uses len(valid_evidence_ids). Verified: a hypothesis citing 3 excerpts with irrelevant verbatim quotes gets ids=3 and outranks a 1-cite hypothesis. Fix: rank on distinct text_sha256 with verify-stage support.
2. H evidence_quote_check.py:142 and :193. Relevance is never checked; reason `text` is ignored. Verified: claim "texture load crash" citing "Module loaded OK" is valid. Fix: document gate as fabrication-only; never count a valid quote as support without verify.
3. M evidence_quote_check.py:140. MIN_CHARS counts punctuation and tags. Verified valid: "------", "[KP-hotbar]", "11:05:33". Fix: require at least 6 letters or digits after stripping a leading [tag] or timestamp.
4. M evidence_quote_check.py:57 and :80-98. `L<n>|` markers are stripped and discarded; `n` is never read. Verified valid: "L9999| Player died at dusk" for line 3501. Fix: map markers to real `n` and reject mismatches.
5. M evidence_quote_check.py:95-98 and :156-157. Identical text under two ids is accepted and both ids count. Verified: one quote citing two identical-text excerpts gives ids=2. Fix: dedupe by text_sha256 in valid_evidence_ids.
6. L evidence_quote_check.py:50 and :142. Fail-closed false negatives, verified rejected: curly quote vs straight, ZWSP inside excerpt, NFD vs NFC. Fix: map quote punctuation and drop Cf characters on both sides.
7. L evidence_quote_check.py:123. Truncated ids `ev:L3500-3503` and `L3500-3503:<sha8>` return "unknown evidence id" with no hint. Fix: name the required `ev:<sha8>` form in the reason.
8. L evidence_quote_check.py:246. Lone surrogate in evidence_id crashes CLI print (UnicodeEncodeError, rc 1). Still a reject, not a pass. Fix: catch in main.

## Handled well (max 4 lines)
- Any bad citation rejects the hypothesis; the substring check runs on one excerpt, so spliced non-adjacent text, ellipsis and case changes are rejected (verified).
- Short ids resolve only on exactly one match; sha8 collision is "ambiguous" (verified). sha8 is 32-bit: about 1% chance of some collision at 10k excerpts, fail-closed.
- Resolved full ids are returned and deduped; a sha8 citation is checked against the excerpt it names.
- Integrity recomputes text_sha256, id suffix and bundle_sha256; NBSP is normalised (verified valid).

## Recommendations (max 5)
1. Rank and count by distinct text_sha256 with verify support (bug_investigate.py:478).
2. Validate `L<n>|` markers against excerpt `n` values.
3. Measure MIN_CHARS on letters and digits after stripping a leading tag or timestamp.
4. State in the docstring that the gate proves verbatim presence only; relevance is the verify unit's job.
5. Add tests for marker mismatch, duplicate-text counting, punctuation-only quotes and the lone-surrogate CLI path.
