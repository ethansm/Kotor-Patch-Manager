## Clusters

- home-path-includes: test.toml and smokes.toml hardcode `-I$HOME/Games/KOTOR2_Mod_Workspace/.../Patches/Common`, which depends on the developer's machine and the shell expanding $HOME, and bypasses the gate's scratch tree. (10 findings)
- selfheal-mi0-dead-branch: The `mi <= 2` predicate already accepts member 0, so the member-0-specific else-if branches (g_pend0, g_auto0, g_lastUseMs0) never run. (2 findings)
- npc-hash-seed-frame: OverrideNpcTexture seeds the diversity hash with the resolver frame address, which is not a stable per-NPC value. (3 findings)
- npc-unsourced-offsets: The dispatcher dereferences hardcoded frame and creature offsets that have no cited source. (6 findings)
- npc-test-ranges: DiversityLogic predicates include 'test' appearance ids and loose prefix tags that overlap vanilla rows or unrelated tags. (3 findings)
- kplog-static-init: Namespace-scope initializers call KpLog_SetFallback* before KPatchInit, and some set INFO level unconditionally. (5 findings)
- mouseprobe-engine-writes: The 0.4.0 mouse fix writes engine memory (deltas, message id) from a probe described as strictly read-only. (4 findings)
- perflab-abreserve-cave: The new abreserve experiment's hand-assembled cave skips the original SetSize call without a verifiable count store, and the header describes it as off-by-default only. (3 findings)
- shadow-replay-baseline: shadow_replay reports 'clef-flash' agreement and speedup from hand-written labels and constant latencies. (4 findings)
- query-ghidra-struct: The --cpp struct output merges classes by substring, ignores size, offset gaps and the row limit, so offsets are not trustworthy. (4 findings)
- stale-comments: Comments and headers were not updated after behavior or version changes. (8 findings)
- hotbar-save-events-migration: Hotbar save hooks moved to the save-events library, leaving folder-form and conflict metadata differences. (4 findings)
