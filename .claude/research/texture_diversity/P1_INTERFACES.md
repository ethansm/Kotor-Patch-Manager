# P1 fixed interfaces (texture diversity B2/B3/B4)

All files under `patch_manager_mods/k1_port/`. No existing file is edited. Python: `.venv/bin/python` (numpy + PIL; no scipy/skimage/cv2/SVG lib).
Tests are colocated `test_*.py`, same style as `test_k1_port_tex_tpc.py` (plain functions in a TESTS list, re-exec into `.venv` when numpy is missing, print `SKIP:` when absent, exit 1 on failure). Row order everywhere = STORED order (row 0 = first stored row, no flip).
Inside the engine colours are float32 0..1 RGB `(h,w,3)`; masks/regions are float32 0..1 `(h,w)` (soft edges); thresholded to bool only at the TPC/gate boundary.
Every module starts with `sys.path.insert(0, str(HERE))` (python -I drops the script dir) and has a module docstring in the style of `k1_port_tex_tpc.py`.

## U1 `k1_port_tex_decals.py` (+ `test_k1_port_tex_decals.py`)
- `DECALS: dict[str, Callable[[int], np.ndarray]]`; each `fn(size) -> alpha (size,size) float32`, centred, drawn with PIL `ImageDraw` at 4x supersample then `Image.LANCZOS` down to `size`, alpha in [0,1].
- 12 shapes, our own original geometry (docstring one-liner "inspired by <theme>; original geometry"): `cog8` (cog ring with eight teeth + hub hole), `sprout` (stem + two leaves), `hawk` (swept-wing bird silhouette), `chevrons3` (three stacked chevrons), `crate_stencil` (box outline with cross + two small bars), `patch_round` (filled disc with ring cut), `jaig_eyes` (two angled slits), `medallion` (ring + inner disc + 4 notches), `star5`, `bar_stack` (three horizontal bars of decreasing width), `sun_disc` (disc + 12 rays), `swoop_stripes` (three curved swoosh stripes).
- `render_decal(name, size, rotation_deg=0.0) -> alpha (size,size) float32` (rotate with PIL BICUBIC around centre, shape preserved); `list_decals() -> list[str]` sorted; unknown name raises `KeyError`.
- Tests: every decal: shape/dtype float32, values in [0,1], coverage (mean alpha) between 0.05 and 0.90 at size 64, not constant, deterministic (two calls equal); rotation keeps shape; unknown name KeyError; list_decals has the 12 names.

## U2 `k1_port_tex_overlay.py` (+ `test_k1_port_tex_overlay.py`) — imports U1 (`from k1_port_tex_decals import DECALS, render_decal`)
- `GRID = 4`; `cell_mask(w, h, cells: list[str]) -> bool (h,w)`: cells "A1".."D4" (col letter A-D left to right, row digit 1-4 top to bottom; each cell is w/4 x h/4 px); raises `ValueError` on bad names.
- `skin_guard(rgb_u8) -> bool (h,w)` True = looks like skin. Predicate (copy, do not import):
  `r,g,b = int32 channels; mx,mn = max/min over channels; (r>95)&(g>40)&(b>20)&((mx-mn)>15)&(abs(r-g)>15)&(r>g)&(r>b)`.
- `region(w, h, cells, islands: dict[str, bool mask], island_labels: list[str], avoid_cells=()) -> float32 (h,w)` = cell_mask(cells) AND union(islands[label] for label in island_labels) AND NOT cell_mask(avoid_cells); an empty `island_labels` means no island restriction; then 1-px feather (3x3 box blur, result in [0,1]). Unknown island label raises `KeyError`.
- Layer ops, each `op(rgb, reg, **params) -> rgb` (float32 in, float32 out, clipped 0..1) and each returns pixels where `reg==0` EXACTLY unchanged (use `out = rgb + reg[...,None]*(new-rgb)`):
  - `recolor_hsv(rgb, reg, hue_shift_deg=0, sat_scale=1, val_scale=1, keep_skin=True)` : hue/sat/val change via numpy rgb<->hsv; when keep_skin the region is multiplied by `~skin_guard(u8(rgb))` first.
  - `band(rgb, reg, orientation='horizontal'|'vertical'|'diagonal', period_px, width_px, colour, opacity, angle_deg=0.0)` : stripes of `width_px` every `period_px` px, `colour` is `#rrggbb`, blended at `opacity*reg`.
  - `decal(rgb, reg, name, cx, cy, size_px, rotation_deg=0.0, colour='#ffffff', opacity=1.0, blend='normal'|'multiply')` : `render_decal` pasted centred at atlas px (cx,cy), alpha multiplied by `reg` (so clipped by region) and `opacity`; partially off-atlas placements are cropped, not an error.
  - `wear(rgb, reg, kind='dust'|'fade'|'stain'|'scuff', strength=0.3, seed=0, direction='down')` : seeded value noise (random grid via `np.random.default_rng(seed)`, bilinear-upsampled, 3 octaves) times a vertical gradient (heavier toward the bottom for 'down', top for 'up', uniform for 'none'); dust lightens towards grey-brown, fade lowers saturation, stain darkens, scuff multiplies speckle. Deterministic per seed, differs between seeds.
  - `tint(rgb, reg, colour, strength=0.3)` : lerp towards colour.
  - `OPS: dict[str, Callable]` maps `"recolor_hsv","band","decal","wear","tint"` to these. `EMBLEM_OPS = {"decal"}`.
- Recipe schema (JSON):
  `{"id":"P3a","family":"commoner","atlas":"n_commm05","model":"n_commm","note":"...","seed":1,"layers":[{"kind":"recolor|trim|emblem|wear","op":"recolor_hsv|band|decal|wear|tint","cells":["A1","B1"],"islands":["torso"],"avoid_cells":["A2"],"card":"K067","params":{...}}]}`.
  `load_recipe(path) -> dict`; `validate_recipe(recipe) -> list[str]` (empty = ok). Rules: required keys id/atlas/model/layers; 1 to 3 layers; at most 1 layer with kind "emblem" and at most 1 decal-op layer; every cell name valid; op in OPS; for op decal `params["name"]` in DECALS; every colour param matches `^#[0-9a-fA-F]{6}$`; layer kind in the four kinds; seed int if present.
  `render_recipe(recipe, parent_rgb_u8, islands) -> (rgb_u8, union_mask_bool)`: float-convert parent, for each layer compute `region(...)` (seed for wear layers = recipe seed + layer index unless params has `seed`), apply op, convert back with rounding; union_mask = (any layer region > 0). Raises `ValueError` if `validate_recipe` is non-empty.
- Tests (synthetic 64x64 gradient atlas, islands = two synthetic bool masks): untouched outside region byte-exact for every op; recolor hue moves where expected and skips synthetic skin-coloured pixels; band period/width counted along a row; decal clipped by a half-region; decal cropped at atlas edge no error; wear deterministic per seed and different per seed; validate_recipe rejects each rule violation (4 layers, 2 emblems, bad cell "E1", unknown op, unknown decal, bad colour); union mask equals union of regions; render_recipe raises on invalid recipe.

## U3 `k1_port_tex_bake.py` (+ `test_k1_port_tex_bake.py`) — imports U1/U2 and P0 modules
Imports: `k1_port_tex_tpc` (`parse`, `decode_mip`, `apply_rgb_edit`), `k1_port_tex_gate` (`gate`, `read_mask`), `k1_port_tex_overlay`, `k1_port_uvmask_overlay` (`_caption`, `compose`, `read_mask`, `load_atlas` as needed).
Constants: `REPO`, `VENV_K1PORT = ~/Games/KOTOR2_Mod_Workspace/venvs/k1port/bin/python`, `DEFAULT_OUT_ROOT = ~/Games/KOTOR2_Mod_Workspace/tex_looks`, `POOL_DIR = <repo>/patch_manager_mods/npc_diversity_src/override`. Output dirs inside the repo or inside the game dir (`~/.local/share/Steam/steamapps/common/Knights of the Old Republic II`) or inside the stage override are REFUSED (exit 2, like `k1_port_uvmask.run_build` does).
Subcommands (argparse):
- `masks --models n_commm:512 n_commf:512 ... --out DIR [--force] [--game DIR]` : for each `model:size` run `[VENV_K1PORT, k1_port_uvmask.py, build, --model M, --atlas A, --size S, --flip 0, --out DIR/masks/M]` (A = `ATLAS_FOR_MODEL` dict: n_commm->n_commm05, n_commf->n_commf02, n_sithcommando->n_sithcom01, n_mandalorian->n_mandalorian01). Skip a model whose `DIR/masks/M/masks.json` exists unless `--force`. Subprocess failure -> exit 1.
- `bake --recipes PATH_OR_DIR --masks DIR --out DIR [--only ID] [--pool-dir DIR] [--game DIR]` : recipes file(s) hold a JSON list of recipe dicts (or one dict). Per recipe: validate FIRST (any invalid recipe aborts the whole run before any write, exit 2, message names the recipe and rule); resolve parent bytes: vanilla pack via `npc_div_texture_sheets._pack_index()` (import from `scripts/`, key `atlas`, `.data`) else `POOL_DIR/<Atlas>.tpc` case-insensitive else exit 2 with reason; a parent whose header is not DXT (`k1_port_tex_tpc.parse` raises ValueError, e.g. TGA/uncompressed) -> that recipe fails with a clear message, exit 2 overall after the rest finish; decode mip 0 RGB (`decode_mip(b, info, 0)[:,:,:3]`); load island masks for `recipe["model"]` from `DIR/masks/<model>/<label>.png` via read_mask -> bool arrays (resize check against atlas size); `render_recipe`; `apply_rgb_edit(parent, rgb, union_mask)`; allocate child name `<family_prefix>NN`: prefix = atlas name without trailing digits (n_commm05 -> n_commm), NN = next free >= 36 per prefix, counter persisted in `OUT/alloc.json` (`{prefix: last_nn}`) and an existing `bake.json` entry with the same recipe id re-uses its child name so re-bakes are stable; write `OUT/tpc/<child>.tpc`; run `gate(parent, child, child_name, [existing filenames in OUT/tpc], mask_pixels)` with `mask_pixels = (w, h, flat bytes 0/255)` built from the union mask directly (no PNG needed); record result. Writes `OUT/bake.json`: `{"run":..., "looks":[{id, family, recipe_sha256, parent, parent_sha256, child, child_sha256, changed_pixel_fraction, changed_block_fraction, decals:[names], gate:[{id,ok,detail}], ok}]}`. Exit 0 only if every gate check of every look passes, 1 if any gate fails, 2 on usage/IO/invalid recipe/unsupported parent.
- `sheets --bake DIR --out DIR` : calls `render_sheets(bake_json_path, out_dir)` (define this function in the same module, or in `k1_port_tex_sheets.py` if the module is too long; the CLI always calls it by this signature). Per family a PNG with one row per look: parent | child | amplified diff (|child-parent| x4, clipped) | region mask, each tile 256 px, caption `"<id> <parent>-><child> changed X.X%"` using the PIL `ImageDraw` caption style of `k1_port_uvmask_overlay._caption`; plus `index.png` with the child tiles of all looks in a grid (4 columns) with captions. Footer on every sheet: `rows in STORED order (row 0 at top)`.
- Tests (synthetic): in-memory DXT1 parent (64x64, 7 mips; build it by `k1_port_tex_tpc` test helpers by copying the builder code from `test_k1_port_tex_tpc.py`) and a DXT5 one written to a tempdir used as `--pool-dir`, plus tiny synthetic mask PNGs written with `k1_port_uvmask.write_png_grey`; recipe with recolor + band; assert gate all ok, blocks outside the region byte-identical, DXT5 alpha bytes identical, alloc counter increments to 36 then 37 and a re-bake keeps names; TGA/uncompressed parent -> exit 2; output dir inside the repo refused (exit 2); recipe with 4 layers refused before any file is written; `sheets` writes index.png and a family PNG.

## Existing API digest (for U3; verified signatures, do not re-read those files)
- `k1_port_tex_tpc`: `parse(b)->dict(w,h,fmt('dxt1'|'dxt5'),mips,offsets,sizes,trailer,header)` raises ValueError for uncompressed/unsupported; `decode_mip(b, info, k)->RGBA uint8 (h,w,4)`; `apply_rgb_edit(parent_bytes, rgb_u8 (h,w,3), mask_bool (h,w)) -> bytes` (same length; unchanged blocks byte-identical).
- `k1_port_tex_dxt`: `encode_rgb(rgb_u8 (h,w,3)) -> colour blocks` (internal); `decode(data,w,h,fmt)`; `BLOCK_BYTES={'dxt1':8,'dxt5':16}`.
- `k1_port_tex_gate.gate(parent: bytes, child: bytes, child_name: str, child_dir_files: list[str], mask_pixels=None) -> list[dict]` each dict `{"id":str,"ok":bool,"detail":str}` (see `_res`); `mask_pixels=(width,height,flat_bytes)` one byte per mip-0 pixel, nonzero = in mask; `read_mask(png_bytes)->(w,h,flat)` (1 = in mask). `child_name` must be a valid resref (check `_check_name`); `child_dir_files` is the list of file names in the child's directory (used for the TXI check).
- `k1_port_uvmask.write_png_grey(path, w, h, grid: bytearray)` (255 = in mask) — import from `k1_port_uvmask` (pure python, safe in .venv). `masks.json` in a mask dir has `{"labels": {label: {"coverage":..,"texels":..}}, ...}`; label PNGs are `<label>.png`.
- `k1_port_uvmask_overlay.read_mask(path)->bool (h,w)`; `_caption(canvas_PIL, x, y, text)` draws black box + yellow text; `LABEL_PX=14`.
- Vanilla pack lookup: `scripts/npc_div_texture_sheets.py` (put `<repo>/scripts` on sys.path, import lazily inside the function) `_pack_index() -> {resref_lower: (erf_path, resource)}`, bytes = `bytes(resource.data)`; slow (reads all packs once), needs pykotor from .venv.
- Test parent builder (copy into the bake test): header = `struct.pack("<IfHHBB", data_size, 1.0, w, h, PIXEL_TYPE, mips)` zero-padded to 128 bytes, PIXEL_TYPE dxt1=2 dxt5=4, data_size = mip-0 byte size; mip sizes `((max(1,w>>k)+3)//4)*((max(1,h>>k)+3)//4)*BLOCK_BYTES[fmt]`. DO NOT fill with random bytes (random DXT1 blocks may be 3-colour mode and fail the gate); build a smooth RGB gradient (h,w,3), encode per mip using `k1_port_tex_tpc.downsample_rgb` + `k1_port_tex_dxt.encode_rgb` + `splice_colour` or simply start from random bytes then run `apply_rgb_edit(parent, gradient, all-ones mask)` to normalise it. For DXT5 also put non-trivial alpha bytes in the alpha half of every block before normalising, and assert they survive.
- Testability hooks required in bake: `resolve_parent(atlas, pool_dir, pack_lookup=None) -> (bytes, source_label)` where `pack_lookup(name)->bytes|None` defaults to the real `_pack_index` lookup; CLI flag `bake --no-pack` skips the vanilla pack (tests use it with `--pool-dir`). `main(argv)->int` is what tests call (no subprocess for bake/sheets; `masks` is not tested beyond argparse).
