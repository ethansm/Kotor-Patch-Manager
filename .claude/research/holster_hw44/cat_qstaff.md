# QSTAFF recon (HW44 edge wave)

Source root: `patch_manager_mods/holster_src/`. Anchors are `file:line` relative to that root. Repo `holster.ini` used as the live ini (game-dir ini not read). Nothing built or run. The closed form in F3 was derived by hand, not numerically checked.

## Premise corrections
- Double-bladed sabers (`w_Dblsbr`) are CatLightsaber, not QStaff (HolsterLogic.h:60). Double-blade swords, gaffi, warblade and pike are CatMelee (HolsterLogic.h:63-65). Only `w_Qtrstaff` is CatQStaff (HolsterLogic.h:~62).
- Repo holster.ini has no active `reach_via_*` line at all. `;reach_via_melee=0` is commented (holster.ini:183). No heavy or rifle reach_via line exists in the repo ini.
- Repo holster.ini has `reach_test=0` (holster.ini:140). The arm reach is off in the repo default. Findings below assume the live config enables it.

## Qstaff geometry (R17 survey, HolsterShape.inc:96-100)
- Long axis is model z (`axis 2`). Length about 1.03 m for `_001`.
- bbox centre at z=0.15, so the grip (weapon origin, which the engine attaches to rhand) sits 0.36 m above the bottom tip and 0.66 m below the top tip.
- Cross-section is round within the bbox (x about y), so roll about the long axis is visually near-free.
- Qstaff has no family fallback (HolsterShape.h:36-38).
