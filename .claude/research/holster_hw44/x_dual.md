## Checked, no defect found (anchors)

- Per-hand isolation of reach state: `ReachEnt` is keyed on (parent, left) at `Holster.cpp:1598-1600`; clears touch only that entry; `reachExtractPct` (`:1537-1541`) and `snapHandDist` (`:2063-2064`) match `left` too.
- Per-hand category in the world: `slideResolve(g_slideTune, cat, ...)` per Ent at `:2507`; `reachArm` takes `cat` per call (`:1594`); `viaOutFor(cat)` per call (`:1722`).
- Left-hand mirror signs: outward `ouL = left ? -1 : 1` (`:1707`); `reachPole` flips loc x for left (`HolsterReach.h:151-160`); hinge outward uses `ouL` (`:1715`); via bump uses `ouW` (`:1724`). Exit lift uses the mount frame (`:1767-1775`), so it follows the mount orientation. UNVERIFIED that the left mount quat is mirrored (mountPose not read).
- Stagger scale: `slowMs(60, x)` is linear (`HolsterSlide.h:245-247`), so stagger share of the slide stays about 17% at x = 1 and x = 8.
- Stagger cancel: reversal back to the current dir clears the pending target (`HolsterSlide.h:122-125`). Stagger is applied to the left hand only (`Holster.cpp:2355`), so draw and stow both run right-first.
