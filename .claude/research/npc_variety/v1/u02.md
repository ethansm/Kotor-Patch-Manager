- Path selectors (WALK_ONCE, CIRCULAR, PATH, RANDOM, START_AT_NEAREST) are checked at walkways:121,133,226,230 (grep hits only).

## Can a UTC VarTable preset these locals? (UNSURE)
- Flags are read via GetLocalBoolean (walkways:332). A VarTable preset only works if the engine writes its Int entries into that boolean store. Not shown in these files. OPEN.
- Both spawn scripts call GN_WalkWayPoints() unconditionally (spawn01:113; ambient:58). Walking only happens if the template's OnSpawn is one of these. Which script the UTC uses is OPEN.
- spawn01 sets no walk flags (all commented out). Documented default is repeat forever (spawn01:31-32). Waypoints are named from the creature tag unless a series is set (spawn01:62-65). Whether flagless walking works depends on the unread GN_WalkWayPoints body. OPEN.
- ambient sets AMBIENT_ANIMATIONS TRUE unconditionally (ambient:27). It sets no walk flag. Ambient anims need no preset.
