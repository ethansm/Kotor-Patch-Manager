## Edge cases / failure modes
- Save-load may not reach 0x55A460 -> per-load reset skipped, old roster persists -> treat save-load as its own case; verify in play log before enabling.
- Tag length offset unconfirmed ([38]:202) -> guard misses tag -> duplicate on reload -> check tagstr in Stage 1 log before random rolls.
- Spawn fires before GIT population settles -> guard misses later tags -> duplicates -> use POP-STABLE gate, not 30 ticks.
- K1-only appearance -> body fault or invisible NPC -> restrict pool to K2 appearances ([38]:211).
- Hostile template in commons -> combat with player -> whitelist neutral templates only ([38]:212).
- Position off walkmesh (no snap on native path, unverified) -> float or sink -> use GIT points ([38]:213).
- Detours share addresses with area-hook-probe (0x568BD0, 0x55A460, 0x533830) -> conflict -> remove that probe at install ([38]:218).
- 261tel branch in AddToArea -> unknown side effects -> keep 261tel out of the roster until decoded ([38]:199).
- Failed native load -> vtable[0](p,1) destroys object -> partial state -> log each step before it runs ([38]:220).
- Repeat visits with persistence on and no despawn -> roster accumulates -> need despawn or persistence off.
- Spawn logs OK but NPC not drawn -> looks spawned, fails visually -> only a user play check can confirm.
