# u08 recon: area suitability for commoner crowds

Angle: which areas suit extra walkers. Reads: P1_area.md (all 53 lines), W1c_walkmesh.md:1-30, k2_utc.tsv via awk only.

## Method (facts)
- k2_utc.tsv: 12,755 module rows raw. Unique after key = lowercase(src base, strip .mod/.rim/_s.rim) + resref (col 2): 3,654 rows.
- Raw counts inflate ~3.5x (case variants 204tel.mod / 204TEL.MOD, plus _s.rim copies).
- `chitin` (284 rows) and `override` (72 rows) excluded: not area-owned.
- loose = app_label (col 6) starts `Commoner_`, `Onderon_Commoner_` or `Twilek_Commoner`.
- strict = loose AND resref starts `n_` AND not `g_` (g_ = thug/quest NPCs).
- hostile proxy = app_label matches Sith|Dark_Jedi|Turret|Droid_Assassin|Soldier|Commando (keyword heuristic, unverified).

## Requirements
- R1 (proposal, untested): eligible = strict >= 5 (loose >= 5 for dan rows, which have no n_ prefix), hostile < 8, all > 5, not ebo.
- R2: each area needs waypoints and walkable faces. 204tel: 48 waypoints (P1:9); ward room 204TELb has 344 of 519 faces walkable (W1c:12).
- R3: key lookups by file base name, not IFO Area_Name. 205tel IFO says `204tel` (P1:32).
- R4: exclude story NPCs from the random pool: Carth, Grenn, g_201thug*, named uniques (P1:27; TSV col 2).

## Edge cases / failure modes
- Duplicate TSV rows (case variants, .mod + _s.rim) -> counts 3.5x high -> dedupe on base + resref before any threshold.
- `Commoner_` label on thugs (g_201thug001, g_201thug003 with k_def_grenspn) -> walkers or clones there break gang scenes -> use strict rule, exclude g_*.
- 205tel has 0 commoners -> commoner-only pool adds nothing -> skip, or use a TSF-officer pool.
- UTC template count is not the spawned population. 204tel: 7 commoner UTCs, 16 GIT creatures total (P1:24) -> per-area GIT instance counts are not measured -> OPEN.
- 205tel WOK lookup returned None (P1:35). Likely cause: looked up by module name, not room name (W1c:9, INFERRED) -> do not place walkers there until room WOKs are read.
- Hostile proxy is keyword-only -> 502ond (12) may be allied soldiers -> manual check before excluding.
- Walker clearance: W1c picks keep 1.5 from GIT positions (W1c:25). Added walkers must also clear each other, not only the GIT set.
