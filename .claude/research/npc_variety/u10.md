## Requirements
- Creature cap per area: no cap in listed ranges -> extra population cannot be sized -> measure baseline vs +N creatures in one common area, set N from data (cap value OPEN).
- Area load time: GIT template path loads one UTC per entry (W1a:18) -> load time grows per added entry (INFERRED, unmeasured) -> time area load at 0 vs +N entries; keep N small.
- AI tick cost: R3:34 (cites U1.md:86, unverified) says each scripted object runs a script per 6 s -> each extra scripted UTC adds tick cost -> give added UTCs empty or minimal OnHeartbeat/OnSpawn scripts; measure.
- Save and object growth: runtime-created creatures persist (R3:52 INFERRED); save writes ScriptSpawn and ObjectId per creature (W1a:20) -> saves grow every pass -> prefer static GIT placement per build; if runtime, remove on area exit (removal path NOT verified, OPEN).
- Models and textures: animations live in the MDL (R3:29, cites 04 s5 risk 6) -> each new model or texture costs load time and texture memory; no numbers in listed ranges -> measure texture memory at 0 vs N aliens; cap distinct models per area.
- Hook cost: SetAppearance hook runs once per creature build (W1a:13; P6:38) -> hook cost scales with creature count -> count hook calls per area load in the probe.
- Measurement counter: RMP log is process-wide and capped at 300 (P6:39) -> late creatures produce no RMP line -> use a dedicated counter; logging probe is a DLL change, needs user GO (P6:47).
- Pathing: alien rows differ in walk/run speed (R3:28, cites 04 s3: Rodian 1.7/5.4 vs commoner 1.813/3.66) -> waypoint loop time differs by row -> time one loop per row.

## Edge cases / failure modes
- Blank modela cell (W1a:29) -> empty model name -> invisible creature still ticks AI -> wasted cost, looks like a missing NPC -> validate appearance row before placement (P6 A2/A3).
- RMP take(300,500) exhausted after call 300 (P6:39) -> no log line for later builds -> false negative in measurement -> a missing RMP line is not evidence of no spawn; use own counter.
- AddToArea flags differ: CreateObject (1,1) vs GIT (param_3,0) (W1a:12; W1a:28) -> runtime and GIT creatures may take different insert paths -> cost and visibility unknown -> test both in one area (OPEN).
- Spawn script firing unknown (W1a:28, Q2 OPEN; CreatnScrptFird flag W1a:15) -> OnSpawn may not run for added creatures -> behaviour and cost differ from vanilla -> one logged one-line spawn script test (R3:59).
- Nested script depth (R3:33 cites nesting cap 8; R3:35 cites VM stack clear, SPECULATIVE) -> chained spawn scripts can hit the cap or corrupt the VM stack -> keep the spawn script flat, no nested situations.
- Object id: default 0x7F000000 (W1a:17; W1a:30); no allocator found (R3:18 MISSING) -> id space limit unknown; large N may collide -> keep N under the measured cap.
- Walkmesh placement: XYZ must lie on the area .wok (P6:34, check A5) -> off-mesh spawn floats or cannot path -> run check A5 on every XYZ before shipping.
