## Edge cases / failure modes
- Save taken after visiting the target module -> nested SAV wins, the GIT edit never reaches that save (P6_test_verify.md:6) -> play test shows no spawn -> false negative. Handle: test only from a pre-visit slot; check which modules are nested.
- No slot is proven pre-Telos; weakest by mtime/size: Game1, Game5, Game8 (P6_test_verify.md:23) -> wrong-era baseline. Handle: confirm AREANAME in the in-game load menu (P6_test_verify.md:24) before forging.
- Quicksave and Autosave overwritten every save (P6_test_verify.md:12) -> not a stable baseline. Handle: forge only from named Game slots.
- Mid-spawn save: AVAILNPC written from the live creature on every save (26_FORCED_STATE_TESTING.md:34-35) -> whether non-party mod NPCs persist is unproven -> they may vanish or be rebuilt on reload. Handle: save, reload, compare each spawned NPC. OPEN.
- RMP rate limit is process-wide: calls 1-300 logged, then only 800, 1300 (P6_test_verify.md:39) -> a PoC built after call 300 has no RMP line. A missing line is not "no spawn". Handle: fresh launch, load the target first.
- Tag-based keep and companion exclusion are dead: tag unreadable, ExcludeKind never assigned (P6_test_verify.md:43) -> companions can be re-skinned. Handle: offline assert that companion oids keep appearance; play-check one companion.
- Keep-by-position 0.3 m (P6_test_verify.md:42) -> a spawn within 0.3 m of a vanilla keep point stays vanilla and looks like "no variety". Handle: A5 1.0 m placement gate.
- ShouldVary (35%) runs before the row check (P6_test_verify.md:44) -> about 65% of custom-row creatures log skip:vary. Handle: treat skip:vary as a label, not a failure.
- pykotor GlobalVars packs LSB-first; the save reads MSB-first (26_FORCED_STATE_TESTING.md:31-32) -> wrong story gates. Handle: MSB-first writer only.
- Steam Cloud syncs a forged slot and its deletion until cleanup (26_FORCED_STATE_TESTING.md:22) -> stray slot on other devices. Handle: cleanup after each test.
- Partial rollback (module restored, override file left) -> mixed vanilla/mod state. Handle: restore both, compare sha256 of each.
- Seed stability: ShouldVary keys on oid + original row (P6_test_verify.md:44). OPEN: does the oid survive save/load? Same oid -> same look on reload; new oid -> re-roll, so one play test cannot confirm a given look.
- Animation variety: neither file covers animation hooks, log markers or tests -> no verification path yet. OPEN.
