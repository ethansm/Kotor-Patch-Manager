## 3. Dependency graph and optional-require semantics

```
gui-input (provider)  <-- equip3d (requires = [gui-input], already)
holster (kind patch, provides k2.holster@1, requires = [])
    ^                                  (only if the editor is a patch of its own)
    |  editor (requires = [holster], requires_interfaces = [k2.holster@1])
equip3d --optional: require(k2.holster) NOT listed--> holster   (WARN; NULL = inert)
editor  --needs equip panel + preview Gob--> equip3d via k2.preview3d (or equip3d-side hook)
```

Facts:
- Holster runs without the editor: holster has `requires = []` (`holster_src/manifest.toml:8`), no requires_interfaces, and its 6 hooks (`holster_src/kotor2-steam-aspyr.hooks.toml`, incl. 0x00504EF5 at :98) are not in any editor manifest. Confirmed.
- Unlisted require() = WARN, not FAIL: `scripts/check_provider_manifests.py:341-342`. Live example: npc-diversity WARN today.
- Listing it in requires_interfaces without requires = FAIL (`check_provider_manifests.py:352-355`). So "optional" means unlisted require() only.
- KPM installer (`KPM/src/KPatchCore/Validators/DependencyValidator.cs`):
  - `requires` naming a provider auto-adds it (:189-191).
  - `requires` naming a normal patch that is not ticked is an install error, "Patch 'X' requires: Y" (:193-194, :201). So equip3d must NOT list `requires = ["holster"]`, or equip3d installs fail without holster.
  - A requested provider that nothing requires is skipped (:293, "Skipped provider"). So holster must NOT become `kind = "provider"`. Ticked alone, its behaviour would be dropped. Provide k2.holster from the normal patch (ranged-ai precedent).
- Hook duplicates: the checker compares hook addresses only for provider-consumer pairs (`check_provider_manifests.py:366`). Editor-vs-holster collisions are not checked here. `save_events_src/manifest.toml` says KPM rejects duplicate hooks; not verified in KPM source.
- Consequence: a dedicated editor cannot re-hook the equip panel. equip3d owns H-E1/H-E3/H-E4 at 0x008AA16A, 0x008ABA50, 0x008AA6F0 (`equipment_3d_character_src/kotor2-steam-aspyr.hooks.toml:6,18,30`). The editor gets the panel and preview Gob from equip3d through a provider (k2.preview3d), or it lives in equip3d's pane.
