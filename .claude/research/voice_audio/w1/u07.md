# u07 findings: voice/audio source claims C1-C4 (verified 2026-10-13)
Method: web search/fetch (JKHub, xoreos doxygen, Wikipedia credits, swg-rs repo, gg.deals) plus read-only counts of local K1/K2 audio folders. No game archive was extracted (JK, SWG, Jade Empire, NWN not installed locally).

C1: PARTIAL - PK3 is a zip, base game has assets0-3.pk3 (https://jkhub.org/wiki/Filesystem). Soundpack path is sound/chars/<name>/misc, SP voices one level up (https://jkhub.org/tutorials/general-modding/how-to-make-character-soundpacks-r61/). No source states stock mp3 vs wav. Folder names gran/trandoshan/reborn/wampa/howler not verified; weequay/rodian are NPC species only (https://jkhub.org/wiki/Weequay). Rancor breathing is "hard-coded" per JKHub thread (weak).
C2: UNSURE - SWG packs data in .TRE archives (https://file-extensions.org/extension/tre). swg-rs crate swg_tre reads/writes TRE, AGPL-3.0 (https://github.com/Smash-Wars-Galaxies/swg-rs). "TRE Explorer" and "SIE" not found in 4 searches. Audio container inside TRE, WAV/MP3 output and creature foley unverified. Steam app 24170 listing exists (https://gg.deals/steam/app/24170); 2026 purchase status unverified.
C3: PARTIAL - PC differs from Xbox. Xbox uses binary XWB; non-Xbox ships ASCII metadata plus loose Ogg Vorbis in subfolders (https://xoreos.org/doxygen/d1/d70/classSound_1_1XACTWaveBank__ASCII.html). Jade Empire PC is 2007 (https://en.wikipedia.org/wiki/Jade_Empire). vgmstream XWB support is in the foobar2000 build changelog r2117 (https://foobar2000.org/components/view/foo_input_vgmstream/release/r1831); vgmstream's own format list not fetched.
C3 cast: Downes CONFIRMED in KOTOR1 (Griff Vao), KOTOR2 (Nikko), Jade Empire (Sagacious Zu) (https://en.wikipedia.org/wiki/Robin_Atkin_Downes). Cam Clarke CONFIRMED in KOTOR1 (Trask Ulgo) and Jade Empire (Sky, Si Pat); not in KOTOR2 (https://en.wikipedia.org/wiki/Cam_Clarke). Brian George is KOTOR1 only (Zhar Lestin); Jade Empire not listed (https://en.wikipedia.org/wiki/Brian_George). Nicky Katt is KOTOR2 only (Atton Rand); Jade Empire not found (Wikipedia Nicky_Katt page).
C4: PARTIAL - NWN SSF is binary, not GFF as nwn-lib claims (https://xoreos.org/doxygen/df/d8e/ssffile_8cpp_source.html). NWN SSF V1.0 entries are 16-char sound filename + StrRef. KotOR SSF V1.1 entries are StrRef only, no resref, so NWN sound names do not transplant as-is. BIF unpack via kivinen keyunpack (https://www.kivinen.iki.fi/nwn/downloads.html, search snippet). NWN WAV format and legality not verified.
LOCAL (K1/K2 base installs, read-only): K1 streamwaves/ = 489 .wav, no StreamVoice dir. K2 StreamVoice/ = 764 .mp3 + 13 .wav. K2 StreamSounds/ = 832 .wav.

## BEYOND
1. K1 barks need no transcoding (489 .wav in streamwaves/). K2 voice is mostly MP3, so K2 reuse needs an MP3 path. Source: local folder counts above.
2. Jedi: Fallen Order (Steam, EA; Wwise): BNK/WEM via Vextil/Wwise-Unpacker (PCK/BNK to OGG/MP3, Windows), wwiser (BNK to XML); vgmstream reads WEM (https://github.com/Vextil/Wwise-Unpacker). Fits droid/Imperial/human barks. EULA: personal-use extraction only (not read).
3. Dragon Age: Origins (FSB3/4/5): aezay "FSB Extractor" and fsbext (https://www.nexusmods.com/dragonage/mods/3477). Same BioWare cast: Downes (Ademaro, Bhelen Crier), Clarke (Herren, Kendrick), Brian George (Greagoir, Ser Otto) per Wikipedia. Fits human NPC barks (guard, merchant, mercenary).
4. Empire at War + Forces of Corruption (2006): game plays WAV; custom sounds need SFX XML entries (https://www.moddb.com/groups/star-wars-modders/tutorials/how-to-add-sounds-in-eaw-foc-mods). Original .MEG archive format not verified. Downes voices Grand Admiral Thrawn and Noghri (Wikipedia). Fits Imperial officer and alien barks.
5. The Force Unleashed and Battlefront II (2005): FSB is a candidate, NOT verified. BF2 community mod names common.bnk under GameData\data\_lvl_pc\sound (https://www.gamepressure.com/download/star-wars-battlefront-ii-2005-bf2-sound-remaster-mod/za12cc1). fsbex supports FSB5 only; python-fsb5 is MIT, last push 2021. Fits clone/trooper/creature barks if confirmed.
Legal, all candidates: commercial copyrighted audio. Personal extraction only, no redistribution. Per-EULA text not read.
Not covered: Republic Commando (no format found in search).
