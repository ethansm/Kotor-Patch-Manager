# u03: SSF layout, soundset.2da, appearance soundset column (K2)

Scope: read-only recon. Parsers and samples: `.claude/waves/w10-voice/tmp/u03/` (k2fmt.py, final.py, gff_utc.py). Full 70-row table: `.claude/research/voice_audio/w1/u03_soundset_rows.tsv`.

C1: PARTIAL - 28 voice slots, names below; but SSF stores only uint32 StrRefs, no 8-char resrefs. Sound names live in dialog.tlk SoundResRef (e.g. `p_bastila_bat1`, 14 chars). Evidence: xoreos ssffile.cpp "KotOR V1.1 ... just a list of StrRefs" https://xoreos.org/doxygen/df/d8e/ssffile_8cpp_source.html ; K2 `p_bastila.ssf` (chitin.key type 2060) -> TLK row 36850.
C2: CONFIRMED - xoreos-tools ships `ssf2xml` and `xml2ssf` (xml2ssf has `--kotor2`). ssf2xml man: KotOR-era SSF stores only StrRefs. https://manpages.debian.org/testing/xoreos-tools/ssf2xml.1.en.html ; https://dyn.manpages.debian.org/unstable/xoreos-tools/xml2ssf.1 (tools not installed locally, not run).
C3: CONFIRMED - UTC `SoundSetFile` is a GFF WORD (type 2) in vanilla UTCs (284 in chitin.key, type 2027). Matches soundset row resref: p_atton=54, p_kreia=48, p_mira=46, n_commm=11, c_drdastro=2. 14 Appearance_Type values have NPCs on different soundset rows (appearance 20: n_darkjedim=55 vs g_darkjedi01=41).
C4: REFUTED - appearance.2da (vanilla and Override, 94 cols each) has no soundset column. Only `footstepsound`, `armor_sound`, `combat_sound`, `soundapptype`.
C5: REFUTED - soundset.2da row 42 is `Gammorean_K2` (a_gamor). No Selkath row in vanilla (66 rows, data/2DA.bif resid 0x17a) or Override (70 rows).

- Vanilla p_bastila.ssf: 28/28 slots -> TLK SoundResRef -> `StreamSounds/P_BASTILA_BAT1.wav` etc. (all present; no StreamVoice copies).
- Override c_hutt, n_rakata, n_tusken, p_mission, p_zaalbar: 0 wavs found in StreamSounds, StreamVoice or Override. Their TLK rows carry sound names (c_hutt 38231-38238, n_rakata 37084-37091), so those lines would be silent.
- p_zaalbar TLK rows 37860-37887 have sound names and no text. Label order is shifted vs K2 (idx0 = bat2, bat1 absent).
- Whether those Override TLK rows are vanilla: UNSURE. dialog.tlk mtime Sep 30 vs install Sep 23; no TLK backup under backups/.

- Vanilla 66 rows (0-65); Override 70 rows (extra 66-69: c_envboss/c_envbos, n_tusken, n_rakata, c_hutt). The file has no rows past 69, so "first 120" = all rows.

## BEYOND
1. Override SSF voice lines for 5 NPCs point at 0 shipped wavs, so they are silent. p_mission keeps subtitle text.
2. K2 voice wavs are uppercase in StreamSounds (`P_BASTILA_BAT1.wav`); StreamVoice has none of Bastila's.
3. rakata's 0-based table matches K2 data, so the "1-indexed" note in its text does not apply to the on-disk table.
4. Resource type IDs confirmed by parsing: 2DA 2017, SSF 2060, UTC 2027. Type 2044 holds `plc_*` names (placeables, inferred); 3008 holds model names (MDX, inferred).
5. Repo has no SSF writer (rg over scripts/ and k1_port/ found none), so the origin of Override SSFs is unknown.
