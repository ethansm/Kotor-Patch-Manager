Primary = README / model card / repo source via WebFetch. "secondary" = blog or aggregator.

C1: PARTIAL - "10-15 s + transcript, ~1-2 s/line" is not what primary docs say; several versions are stale.
  - F5-TTS: code MIT, weights CC-BY-NC (github.com/SWivid/F5-TTS). Latest on README = v1 Base (2025-03-12); no 2026 release found. Ref text auto-ASR if omitted. RTF 0.0394 on L20 (README).
  - Chatterbox: MIT (repo LICENSE). Conditioning 10 s (S3Gen) + 6 s (speech prompt), no transcript (src/chatterbox/tts.py). Sample rate value not shown in fetched source.
  - CosyVoice: v2 is superseded; latest is Fun-CosyVoice3-0.5B-2512 (roadmap 2025/12). Code Apache-2.0; weights licence not stated on page (github.com/FunAudioLLM/CosyVoice).
  - GPT-SoVITS: README latest = V5 (no date shown); releases page stops at v2Pro 2025-06-06. Ref clip = 5 s. Native output v3 24 kHz, v4 48 kHz. Emotion control = to-do only (github.com/RVC-Boss/GPT-SoVITS).
  - XTTS-v2: model card licence = Coqui Public Model License (huggingface.co/coqui/XTTS-v2), 24 kHz, 6 s clone, no transcript. Repo code = MPL-2.0 (github.com/coqui-ai/TTS). "Non-commercial" is CPML text, not on the card.
  - 1-2 s/line: UNSURE. No 5070 benchmark; RTF 0.04 on L20 suggests sub-second per 5 s line for F5.

C2: PARTIAL - no-watermark holds only by README silence for most models; Chatterbox is REFUTED.
  - Chatterbox: REFUTED. apply_watermark() is called unconditionally in generate() (src/chatterbox/tts.py). Perth watermark on every output.
  - F5-TTS, XTTS-v2, CosyVoice, GPT-SoVITS: no watermark mention on primary pages; code not audited. Censorship not tested.

## BEYOND
1. VibeVoice-TTS code removed by Microsoft (notice 2025-09-05, "instances ... used in ways inconsistent with the stated intent"); TTS weights marked Disabled. Archive weights early (github.com/microsoft/VibeVoice).
2. PyTorch: cu128 wheels leave CI in April 2026; stable PyPI is CUDA 13.0 and lists Blackwell 12.0. For RTX 5070 use cu130 (dev-discuss.pytorch.org release 2.12 post).
3. Licence traps: Fish code and weights = FISH AUDIO RESEARCH LICENSE; Higgs v3 weights = Research and Non-Commercial; IndexTTS-2 = bilibili Model Use License, not Apache (github.com/index-tts/index-tts).
4. Qwen3-TTS Base takes no instruct argument. Emotion needs the CustomVoice/VoiceDesign variants, which do not clone (huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-Base).
5. Maya1 designs voices from a text description (no clone), with <laugh>/<cry>/<whisper> tags (huggingface.co/maya-research/maya1). Best fit for non-human voices as a design, not as a clone.
