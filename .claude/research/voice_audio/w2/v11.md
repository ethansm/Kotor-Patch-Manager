## BEYOND
1. appearance.2da header has per-row texture columns (texa..texn, texaevil, headtexve/headtexe/headtexg/headtexvg). A row can point at new texture names with no MDL edit. Column names verified; engine resolution of new names NOT yet tested. Source: repo appearance.2da line 2.
2. Supermodel is a fixed 32-byte field at MDL header offset 136, so a same-length in-place byte edit is possible. xoreos resolves it recursively (model_kotor.cpp L321-338). A shell model with no anims could borrow a humanoid chain (s_male01 per repo doc 10), but its skeleton must match (inference).
3. Converter gotchas: Xbox skin bone indices are int16 (xoreos readSkin ~L927-935, skip 8 vs 12). K2 adds 8 B to the trimesh header. KotorBlender detects variant from fn_ptr1 (reader.py ~L108-111), not extension. Branch on both.
4. Name-collision risk: Vanilla Characters HD (deadlystream topic 12248) and the Red11BY ESRGAN 2048px NPC pack (dsogaming.com) both replace NPC textures. Overlay texture names must not collide, or load order decides which one wins. Check before publishing.
5. Species-keyed voice precedent: "K1 Ported Alien VO Replacements" (Ashton Scorpius, deadlystream topic 6901) swaps Nikto, Aqualish, Gran, Quarren voice-overs. A native-hook dispatcher can key the same way. Whether LIP files need matching is unverified.
