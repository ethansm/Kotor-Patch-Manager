# w2 v05: K2 StreamVoice/AVO deep dive (1,436 clips, 198 folders)

Catalog: `.claude/research/voice_audio/catalog/k2_avo_bank.tsv` (198 folder rows; clip-level inventory in tmp/v05/avo_base.json). Hashes reused from `.claude/waves/w10-voice/tmp/u05/hashes.tsv`. Durations: MP3 frame count (tmp/v05/mp3dur.py).

## Facts

F1: Inventory: 1,436 clips (1,428 `.wav`, 8 `.mp3`), 1,414 distinct md5 (22 byte-identical copies), 9,146 s total, 9,048 s unique, median 6.0 s. Durations checked against ffmpeg on 16 samples: within 0.05 s (LAME encoder delay).
F2: CORRECTION to W1 u05: its "median 1.65 s" assumed 8-bit 22.05 kHz PCM. The payload is 32 kHz MP3 at 48 kbps behind a 58-byte fake RIFF (bytes 0-57), so the real median is 6.0 s.
F3: Folder name = `_` + species + sex/variant + emotion code: `_RodiFAn` = Rodian, female, Angry. Codes: An=angry, Cmn=comment_generic, Gre=greeting, Hap=happy_thankful, Laf=laughter, Moc=laughter_mocking, Ple=pleading, Que=question, Sa=sad, Sca=scared, Sed=seductive, Wou=wounded, Scr=screaming. These match the alienvo.2da column stems.
F4: File name = `AVO_` + species + sex + full emotion (Ang, Cmnt, Gret, Hapy, Laff, Mock, Pled, Ques, Sad, Scar, Sedu, Woun, Scrm) + length S/M/L + variant 1-3. Length is a real duration class: S median 3.3 s, M 6.6 s, L 10.3 s. 473 of 486 families have 3 variants, so a full folder is 3 lengths x 3 variants = 9 clips.
F5 (alienvo.2da, non-DLG): vanilla `data/2DA.bif` alienvo = 43 species rows x 35 cells. Cells are family names (no variant digit): 659 cells, 472 resolve to disk, 187 dangle. Resolution per species: Twi'lek 87/87, Rodian 72/72, Gamorrean 18/18, Devaronian 27/27, Hutt 16/16, Ithorian 13/13, Trandoshan 6/6, Selkath 7/46, Jawa 0/6, Shyriiwook 0/60 (matches R4). Engine: swkotor2.exe has the string "AlienVO" once. Ghidra DB: `CTwoDimArrays::Load2DArrays_AlienVO` (GOG 0x00486470, Steam 0x006ED4D0) and `InitializePseudoRandomAlienVOVariation` (GOG 0x00758780, 338 B, suggests a variant pick). Caller and row selector not decompiled.
F6 (game Override copy): `Override/alienvo.2da` (md5 61b17261) is NOT vanilla (vanilla md5 2d4431f7). It adds Gand question/sad cells and changes the T3 row. `mod12_k2cp/tslpatchdata/alienvo.2da` = vanilla md5. `tslrcm/override/alienvo.2da` differs in the T3 row. Override AVO_T3M4QUESS1-3.wav are byte-identical to the StreamVoice copies.
F7 (DLG, which species): 384 AVO VO nodes, 172 clip names, 2 dangling names (`avo_twilfcomntl3`, `avo_chandhapys7`). Denominator: 17,104 VO nodes module-only (2.2%, matches W1); 21,375 with BIF DLGs added (1.8%). Lines / distinct clips / DLG count: Twi'lek 88/54/18; Selkath 60/7/11; Jawa 38/6/4; Rodian 36/27/8; Shyriiwook 33/3/6; Duros 24/9/4; Trandoshan 23/10/1; Ithorian 22/13/3; Sith assassin 16/11/2; Hanharr 14/10/4; Hutt 10/9/1; others <=6.
F8 (non-DLG paths): soundset.2da has no AVO name (row 25 Generic_Alien uses a_aliengen). TLK: exactly 2 rows carry AVO SoundResRefs and real subtitles: strref 133976 "You can go in." (AVO_GranCmntS1) and 133977 "Keep quiet about this place." (AVO_granangs3). Scripts: 279 .nss, 519 .ncs and 236 raw .dlg in 01_extracted have 0 AVO script hits. 1 raw DLG hit (mod99 Source/Sion/module/sion_cut.dlg). 02_processed is empty. patch_manager_mods: AVO appears only in address-DB batch files and engine notes (the alienvo loader symbol); no mod script uses AVO.
F9 (LIP): 822 of 1,436 clips have a LIP in vanilla `lips/*.mod` (79 archives). Per species: Twi'lek 72%, Hutt 69%, Sullustan 60%, Rodian 43%, Devaronian 30%, Selkath 0%, Jawa 0%, Shyriiwook 0%. Vanilla Selkath/Jawa/Shyriiwook DLG lines play with no LIP, so a missing LIP does not crash (inferred, not tested in-game).
F10 (Q4, translated text on an AVO clip): Mechanically yes. VO_ResRef is a bare resref and vanilla already does this 384 times. Vanilla AVO nodes often use StrRef -1 (voice only, R4), so custom subtitle text needs its own TLK strref on the node. Constraints: name only clips on disk; LIP coverage per F9; match the clip's emotion to the line.
F11 (Q4, clips per emotion, distinct md5, all variants and lengths): Twi'lek (261 clips, 1,783 s): An 27, Cmn 27, Hap 27, Laf 27, Que 27, Sa 27, Sca 27, Ple 18, Moc 18, Gre 18, Sed 18. Five species chosen by DLG AVO line count.
F12 (Q5, variety): Monte Carlo, 20k trials of 30 lines. Each line picks emotion, then length, then variant uniformly. Repeated lines / P(any repeat) / adjacent identical: Twi'lek 1.7 / 0.84 / 0.11; Rodian 2.0 / 0.89 / 0.14; Selkath 23.1 / 1.00 / 4.3; Jawa 24.0 / 1.00 / 4.8; Shyriiwook 26.0 / 1.00 / 8.1. Single-emotion 30-line events on Twi'lek or Rodian (18-27 clips) repeat about 12-15 lines.
F13 (Q5, total seconds): A 30-line event at the overall median clip length (6.0 s) needs ~180 s of distinct audio. Twi'lek (1,783 s) and Rodian (1,443 s) can supply it. Selkath (66 s), Jawa (39 s) and Shyriiwook (29 s) cannot, so use subtitle-only or a short line count. Hutt (48 clips, 290 s on disk, DLG uses 9) is in between.
