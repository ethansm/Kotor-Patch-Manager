## Structure and format (task 1, task 4)

F1: 13,799 files, all `.wav`, 548,135,774 bytes. 489 at root (480 `n_`/`N_` prefix + 9 others) and 13,310 at depth 3 (`<top>/<speaker>/<file>`), 81 top-level dirs (80 `mNNxx` modules + `globe`), 568 speaker subfolders.
F2: Container on all 13,799: fake RIFF header, 58 bytes. RIFF size field = 50, fmt chunk (18 bytes) claims PCM 22050 Hz 8-bit mono, `fact` chunk, `data` chunk size = 0. Payload starts at byte 58.
F3: Payload is MPEG-1 Layer III, 32 kHz, mono, CBR 48 kbps: 13,796 files, frame-walk with 0 bad hops. 3 files start with an ID3v2 tag at byte 58: `m01aa/c05001/nm01aac05001000_.wav`, `m01aa/tras02/NM01AATRAS02000_.wav`, `m35aa/sith13/NM35AASITH13002_.wav`.
F4: Duration total 91,222 s = 25.3 h (median 6.5 s, p90 10.3 s, max 26.0 s, min 0.25 s). Derived from MP3 frame count (1152 samples/frame). ffmpeg decode of 6 samples agrees within 0.1 s (e.g. 7.23 s vs 7.31 s).
F5: K1 is NOT plain PCM WAV. ffmpeg as-is probes it as `pcm_u8 22050 Hz` and reports 1.99 s for a 7.3 s clip. Decode needs the 58-byte skip: `tail -c +59 f.wav | ffmpeg -f mp3 -i pipe:0 ...` gives `pcm_s16le 32000 Hz mono`.
F6: K2 StreamVoice sample (300 random `.wav` of 17,299): same header claims (PCM 22050/8/mono, RIFF size 50) in 300/300, MP3 sync at byte 58 in 300/300. 295 at 48 kbps/32 kHz; 5 at 128 or 192 kbps; 2 at 44.1 kHz. Container is identical to K1.
F7: Format answer (task 4): no transcode is needed for K1 to K2 format parity, because K2 VO uses the same container. Conversion is only needed for tools that trust the header (plain WAV readers) and for the 3 ID3-tagged files if a strict MP3 reader is used. In-game acceptance of K1 clips in K2 is UNTESTED (same open item as W1).

## Pipeline (task 3, doc 38 section 8)

F16: `k1_port` has no audio model. Ingest only takes `.mdl/.mdx` (MODEL_EXTS) and `.tpc/.tga`. KINDS = texture|model|other. Only `patch_manager_mods/k1_port/test_k1_port_model.py:179` names a stream dir, and that is a fake-K2 test scaffold. Audio would need `adopt --kind other` or `derive --kind other`.
F17: Commands for audio: `k1_port_prune.py adopt --file PATH --kind other --source-id vanilla_k1` (PATH must resolve under the stage root, so K1 install files must be copied into the stage first; `adopt` refuses files outside it); `list`; `prune` (dry-run unless --apply); `approve`; `gate PATH...`; `credits`.
F18: Ledger fields per entry: file, kind, source_id, sha256, license_class, removal_group (`pending_author_approval` when requires_author_approval and not approved), author_approved, credits. Derived copies add parent_file, parent sha, and AI metadata. Classes: vanilla 0, open 1, credit_required 2, unknown 8, personal_use_only 9, permission_required 10.
F19: Gate: blocks any file whose sha256 matches a flagged entry (any file type). Basename fallback only for flagged entries with no sha. The unregistered-asset WARNING fires only for `.tpc/.tga/.mdl/.mdx` (ASSET_SUFFIXES), so unregistered `.wav/.mp3/.lip` pass silently, even with --strict.
F20: Licence gap: `sources.json` `vanilla_k1` = class vanilla, requires_author_approval false, note "Never committed or redistributed from the repo". Gate never flags vanilla, so no tool enforces the no-redistribution note for K1 audio.
