# w4 unit c6: independent reproduction of voice/audio counts (raw bytes)

Scripts: `.claude/waves/w10-voice/tmp/c6/repro_c6.py`, `breakdown_c6.py` (run `python3 -I`; outputs `*.out.txt` beside them).
Method: os.walk with followlinks=False, 1 KiB header reads; cross-checked with `find -iname` and `head -c 4`.
Caveat: StreamVoice has 588 directory aliases (e.g. `gbl -> GBL`). Following them gives 38,697 wav / 1,212 mp3 (double count). Doc numbers match physical files only.
