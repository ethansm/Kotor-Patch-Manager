# b4: voice kits for the NPC pool and silent commoners (w10-voice w3)

Read-only. Ground truth: W1/W2 facts plus catalogs. Game dirs untouched, no in-game test. (A) = assumption.
## Facts used
- n_commm (SS 11) = 74 of 293 commoner-body templates. Its 6 TLK-linked slots (TLK 36701-36703) have empty sound and empty text (w2/v03 F11). Female n_commonf (SS 57) is 3/4 voiced.
- Pool: 10/16 rows Twi'lek. 6 male-body rows (802, 805-808, 812). Voice = template SoundSetFile, not the pool row (w2/v08 F1, F13).
- Live look seed = creature oid (NpcDiversityDispatcher.cpp:493; DiversityLogic.h:152,164). Doc 34 HashCreatureSpawn(area,x,y,tag) is dead code.
- SoundSetFile WORD written at stats+0x10EC inside LoadCreature 0x6AFED0 (patch_manager_mods/engine_research_findings/V6.md:176, static). r2.md has no 0x10EC (it gives slots +0x314/+0x384).
- Rows 67 (n_tusken) and 68 (n_rakata) are Override-only. Their 12 clips each exist in neither StreamSounds nor Sounds.bif (w2/v03 F1, F13).
## Ideas
### I1 Global male-commoner SSF | feas 4 | value 3 | risk 2 | ready, gated by E4
- Experience: every male commoner grunts on attack, pain, death.
- Mechanism: loose Override n_commm.ssf (SSF V1.1, 28 StrRefs, u03 layout) pointing at existing TLK rows that already carry text and SoundResRef (human-male grunts from n_repsold row 15, n_sithsoldr row 18). SoundSetFile stays 11: no 2DA, no runtime write, no save state. Sound resolves via TLK SoundResRef (W1 C1; bark path unconfirmed, E4). Override over chitin precedence (A).
- Assets: K2 clip names only (player's own install), no bytes shipped. Side effect: sleyoverseer1 and merc1_batono (also SS 11) start speaking.
- Test: E4 with one borrowed row, then E7 (new): Override SSF beats chitin.
### I2 Species rescue for Twi'lek looks | feas 3 | value 3 | risk 2 | needs E5
- Experience: Twi'lek-looking NPCs (805-808 male; 809-811, 815-817 female) speak Twi'lek grunts. a_twimale (row 30, 8/8 voiced), a_twifem (row 31, 7/8; a_twifem_die1 silent).
- Mechanism: runtime SoundSetFile write to row 30/31 at LoadCreature 0x6AFED0. Existing rows only, no 2DA or TLK change. A remap-time write is the wrong place (w2/v08 F14).
- Blocker: the voice key must equal the look key. The look uses oid; oid stability across save/load is UNVERIFIED (doc 34 line 274). A tag+area+x/y key needs a matching look change.
- Test: E5 on one Twi'lek remap. Write row 30, check grunts, save, reload, check row and look.
### I3 Per-NPC kits (archetype x hash) | feas 2 | value 4 | risk 3 | needs E2, E5, E6, 2DA merge
- Experience: each male commoner keeps one of ~4-6 voices across reloads.
- Mechanism: kit SSFs kpk_m01..m06 plus soundset rows. Per-NPC SoundSetFile written at 0x6AFED0 from hash(area,tag,x,y). Route (a): append 2DA rows and TLK rows (TLK append is positional, see scripts/append_ranged_kite_tlk.py). Route (b): runtime write to existing indices, no 2DA. Avoid index 70 (g_xor) and 103 (tar03_swoopie1).
- Risk: Override soundset.2da has 70 rows, incl. 67-69 from another mod. A whole-file snapshot erases them, so merge only. Mod removed leaves out-of-range rows: silent, since vanilla g_xor (SS 70) loads (A).
- Test: append one row (e.g., 104) plus kpk_m01.ssf. Write one NPC, save, reload, remove mod, reload.
### I4 K1 male-citizen clips as kit source | feas 3 | value 3 | risk 4 | personal use only
- K1 has no human-male species group in k1_streamwaves_groups.tsv. Only 'probable' citizen groups: m02ab/male12 (14), male13 (13), m02ae/male20 (10), male21 (10), m45aa/male06 (2) = 49 files. Speaker hints are plot lines, so audition first.
- Emotion tags COM/ANG/GRT/SAD map 1:1 to K2 (w2/v04 F15). Slot map (ANG to battlecry/attack, SAD to dead) is a proposal, untested.
- Format: 58-byte header + MPEG-1 L3 32 kHz mono, same as K2 VO, no transcode (W1 C4, W2). Delivery: rename-copy under the resref the TLK row names (E1), or via I1 SSF.
- Legal: K1 bytes. Never in a release.
### I5 Fill rows 67/68 by rename | feas 4 | value 2 | risk 4 | needs E1
- Experience: Tusken and Rakata templates on SS 67/68 gain grunts.
- Mechanism: TLK rows already name n_tusken_bat1..dead and n_rakata_*. A loose file with the same resref fills the slot. No 2DA, TLK or runtime change. K1 supply: N_GTUSKEN 13 files, N_GWRAKATA 27, N_GRAKATA 27.
- Blocker: which live templates use 67/68 (not counted); which mod added 67-69.
- Test: E1 with one renamed N_GTUSKEN clip as n_tusken_bat1.wav in Override.
### I6 Designed-voice synthetic kit | feas 3 | value 4 | risk 2 | after E1, E2
- Experience: new human-male commoner voices with no game audio.
- Mechanism: 6 clips per kit (battlecry, attack x2, pain x2, dead) as 58-byte-header MP3 (E2) or RIFF. Delivered via I1 SSF.
- Legal: ElevenLabs Voice Design (own design, not a clone) is OK for personal use. PVC is own-voice only. SynthID watermark. Free tier: no commercial use. Nexus requires AI-Generated tag (W1). Chatterbox always watermarks; F5-TTS and XTTS are non-commercial.
- Test: E2 with 6 designed clips through the I1 SSF.
