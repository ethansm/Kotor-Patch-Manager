# b9 kvoice pipeline spec (condensed by orchestrator from the unit reply; prototype in .claude/waves/w10-voice/tmp/b9/)
Verdict: round trip PASS (strip -> loudness normalize -> MP3 encode -> 58-byte prefix -> verify -> decode-back; duration delta 0.0 ms; 15/15 prototype tests).

## 58-byte VO container (measured identical in 3/3 copied + 20/20 sampled StreamVoice clips)
off0 'RIFF'; off4 RIFF size = 50 (constant); off8 'WAVE','fmt '; off16 fmt size 18; off20 tag 1 / ch 1; off24 rate 22050 declared (real audio 32000); off32 blockAlign 1 / bits 8; off36 cbSize 0; off38 'fact' size 4 sampleLen 0; off50 'data' size 0; off58 MP3 frames ff fb 38 c4 = MPEG-1 L3 48 kbps 32 kHz mono. Frame 0 is a CBR Info frame; frame size 216 B => file size = 58 + 216*frames. Decoded samples = (frames-1)*1152 - 1105 (LAME gapless trim). Cosmetic diffs from vanilla: encoder tag Lavc vs LAME3.x.
- Vanilla also ships bare MP3 at 44.1 kHz 128 kbps mono (417-byte frames), e.g. StreamVoice/tatnpcmale1.mp3 (`--container bare` for E2).
- r2's 0x1D6 seek: if it applies to loose VO the seek lands in audio frame 1 (~36 ms at risk); keep >=120 ms lead-in silence on every clip (test E2).

## Loudness corpus (20 random StreamVoice wavs)
median -18.5 LUFS (Q1 -21.3, Q3 -17.2, sd 2.6, range -22.6..-14.0); TP median -2.5 dBTP max +0.1; LRA useless on short clips. Target -18.5 LUFS, TP ceiling -1.0 dBTP, up to 3 passes, tol 0.3 LU.

## Layout: patch_manager_mods/kvoice/ (flat like k1_port/)
kvoice_container.py (build_header/detect/strip/wrap/walk_frames), kvoice_audio.py (decode_pcm/measure/encode), kvoice_norm.py, kvoice_lip.py (write_lip enforces first key t=0, last key = duration; check_lip; Rhubarb remap), kvoice_ledger.py (wraps k1_port_sources.Ledger), kvoice_pack.py + kvoice.py (CLI, stage writer), kvoice_verify.py.
Stage: <stage>/Override/<resref>.wav (58B container) + .lip + manifest.json (sha256) + ledger.json (k1_port schema 1).
CLI: probe-header | measure | ingest <src> --as vanilla58|bare_mp3|pcm|ogg|tts | clip <src> --resref <r16> --source-id vanilla_k2|tts_<model> --stage <dir> [--lip cues.tsv|--rhubarb tsv] [--personal] [--container wav58|bare] | verify <stage> | ledger show|flag.
Verifier rules R1 RIFF@0; R2 no RIFF@0x1D6; R3 bytes 0-57 == build_header(); R4 frame chain reaches EOF, 32k/mono/48k; R5 size formula; R6 ffmpeg decode OK; R7 .lip magic/count/first key 0/last key=length/monotonic/shape 0-15; R8 lip within 1 frame (36 ms) of duration (own tolerance); R9 resref 1-16 [a-z0-9_], wav+lip paired, sha matches, ledger row per file, nothing local_only in a shippable stage. Structure only: does not prove the engine plays it.
