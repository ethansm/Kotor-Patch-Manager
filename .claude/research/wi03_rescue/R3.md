## 5. Proposed pure helper for a bodyvar branch (add to Inv3dLogic.h after fitLookup, ~line 153)
```cpp
// Pure: fit-table var key for an item. cat 2 = plain model -> item variant byte; cat 4 = armor -> body variant byte;
// otherwise -1 (no fit lookup). Byte outside 0..255 -> -1.
inline int fitVarFor(int cat, int itemVar, int bodyVar) {
    int v = (cat == 2) ? itemVar : (cat == 4) ? bodyVar : -1;
    return (v < 0 || v > 255) ? -1 : v;
}
```
- Signature: `inline int fitVarFor(int cat, int itemVar, int bodyVar)`.
- Test: add next to the fitLookup block in inv3d_logic_test.cpp (~line 341), colocated per repo convention.
- Caveat: cat 4 semantics (what bodyVar means for armor) is unverified.
