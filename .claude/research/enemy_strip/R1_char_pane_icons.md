# R1: character-pane effect icons (recon, read-only)

Paths are relative to the KOTOR-II worktree. "UNPROVEN" = not seen in code or on disk.

## (1) Lookup chain (CharEffectsPanel.cpp)
- Entry: `collect()` :415 walks the effect array (server+EffArrOff), reads type +0x08, sub +0x0A, spell id +0x1c, ints count +0x30 / ints ptr +0x34 (:59-60).
- Path A, type 0x43 (EffectIcon): ints[0] = effecticon.2da row (:428). Name/icon/good from mod table `kEffIconRows` (EffectNameTable.inc, struct EffIconRow {name, icon, good}) (:449-453).
  - good==0 -> harmful; good==1 -> beneficial; good==-1 -> harmful iff `kDebuffIcons[spell]` non-null (:450-451).
  - Key = 0x10000+row (:452). Null row or nameless row -> skipped (:446-447).
- Path B, any other type with spell id >= 0: debuff table `kDebuffIcons[spell].resref` first (harmful, :465), else buff table `kEffectIcons[spell]` (:461). Neither -> "untracked spell", skipped (:463).
  - Skipped when an EffectIcon sibling carries the same spell id (`iconCovered`, :434-436, :462).
  - Name = `kSpellRows[spell].name` (:466) else "Effect N". `kSpellRows[].icon` is never read by code.
- Fallback: empty icon or texture not loaded -> `g_cfg.fallbackIcon` (:339-340), INI `fallback_icon`, default "ip_mind" (:127, chareffects.ini:35).
- Null texture is pooled as null for the session: `imageFor` (:253) -> guikit::imageFor (GuiKit.h:334) -> imageLookup(poolNull=true) (GuiKit.h:317-332).
- Shared helpers `k2fx::iconForSpell` (EffectIcons.h:17) and `iconForEffectIconEffect` (:28) are NOT called by the panel. Only `k2fx::currentTime` (:420) and `k2fx::isItemAbility` (:469) are. The panel inlines the same lookup.

## (2) Icon namespace, size, draw primitive
- Prefixes: ip_* = spell/force-power icons; ii_*/iw_* = item icons (-> round disc); i_goodfull/i_evilfull = effecticon 60/62, nameless, never drawn.
- Disc: `DiscResref = "buffhud_circle"` (:86), tint DiscTeal (:85). Source override/buffhud_circle.tga, 128x128 (buff_duration_hud_src/buffhud_circle.tga).
- Draw: label controls LBL_EFX_I00..13 (mirror_character_page.py:17). Fill = border+0x74 via `guikit::setFill` (GuiKit.h:345). Engine CSWGuiBorder::Draw does the drawing (GuiKit.h:361 comment). Not Gui2D::drawImage (Gui2D.h:101), which this panel does not include.
- Slot size: IconW=10, IconH=18 GUI units (:73), placed at X0, y+(RowH-IconH)/2 (:639). Disc drawn before icon (control order, 14_character_active_effects_panel.md:86).
- Vanilla texture: ip_fear/horror/insanity/mind/speedburst/affliction/armor are 32x32 RGBA TPC in TexturePacks/swpc_tex_gui.erf (header read, vanilla_clean).
- Live Steam override: override/ip_fear.tga, ip_horror.tga, ip_insanity.tga are 128x128 32-bit TGA. sha1 matches 01_extracted/mod125_icon_overhaul "AI Enhanced" files. Override beats TexturePacks (14_character_active_effects_panel.md:80). So live icons are 128x128, downscaled into 10x18.
- ip_mind.tga in live override is 65580 bytes (same size as 128x128 TGAs); dims UNPROVEN.
- Fill style (stretch/tile/centre) for LBL_EFX_I: panel never calls setFillStyle (GuiKit.h:381). UNPROVEN.

## (4) Debuff vs buff: decision and tint
- Decision: spell rows = membership in kDebuffIcons (non-null -> HARMFUL, :465). 0x43 rows = good flag (:450-451).
- Rows 201 and 269 (DROID_TRICK, DROID_CONFUSION) are in both tables. Panel picks debuff first (:468). shared collectBuffs(debuff=false) would pick buff.
- Icon tint: always White {1,1,1} (:640). Harmful does NOT tint the icon.
- Disc tint: DiscTeal {0.035,0.415,0.34} for every item icon, harmful or not (:641).
- Harmful is shown by: section order (harmful first, :513, :522), GUI-fixed section text colours (14_character doc:86), and time text Orange when harmful or remaining < soon_s (:668-669).
