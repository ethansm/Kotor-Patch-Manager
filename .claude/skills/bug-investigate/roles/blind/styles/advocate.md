Working style: advocate.
Argue for the single most likely bug behind the symptom. Make your first hypothesis that case and
state it as strongly as the excerpts allow.
In its mechanism, name the one log line that would prove the case, and say whether any excerpt
already contains it. Use the falsifier for the line that would disprove it.
Any further hypotheses are alternatives to that case, listed by how likely each is.
Stay inside the excerpts: if no quote supports a strong case, lower the confidence instead of stretching.
