# R9 - name transfer for the functions touched by R1-R8 (Steam swkotor2.exe, sha256 6a522e71...)

## Summary (5 lines)
1. 216 functions from R1-R8 tables reviewed (skipping rows whose name_map entry is already high, and name_map medium rows whose mapper vote reproduces the same name); GOG->Steam anchors found for about 177 of them, the rest are template/inline/CRT code with no GOG counterpart (listed at the end).
2. Method that worked: local per-region delta from voted neighbours plus **GOG function size = gap to next GOG address vs Steam `size=`** (within ~5%) plus param-bytes vs `ret N`; this fixed several mapper mis-votes (0x55bb80, 0x435720, 0x73a380) and named the 0x42xxxx/0x43xxxx texture and GL region (Global::AurTexture*, GLRender::Create*Texture, GLRender::InitExtensions).
3. Wrong R-file names found: 0x53af20 is CServerExoAppInternal::DoPCAutosave (not SaveGame); 0x4d9ff0 is Material::Constructor (6 texture SafePointers, not a CAurObject base); 0x940550 is CResHelper<CResTPC>::SetResRef (not Init); 0x51bc20 is the CServerExoApp wrapper ctor; 0x465c90 is Global::ProjectDynamicShadow (not MakeLightVec); 0x40f620 is CSWGuiPanel::InitControl (R8 "float helper" wrong).
4. name_map rows that look wrong (details below): 0x781be0 (is MainLoop, not Initialize), 0x73f9c0 (MainLoop stub, not IsClientInitialized), 0x552a90/0x552c90 (Initialize and Put swapped), 0x783dc0 (UpdateRoom, StallServerCode is 0x783d80), 0x73dd20 (CExoFileInternal::Read_2, not GetAccelerationVector), 0x54aa10 (CExoLinkedList AddHead, not ClearAction), 0x6527c0/0x652810 (false grass votes). Rows R7/R8 doubted but that are RIGHT: 0x77a9e0 GetBehaviors, 0x77e650 GetPersonalActions, 0x5453c0 GetArea, 0x711e60 Dump.
5. All CExoResMan rows in name_map (0x711a30..0x715c00) verified: every one sits at the exact delta 0xF66A0 with ret N == GOG param bytes and sizes within 6%; the three `low` ones (0x713e80 ServiceFromImage, 0x714300 Update, 0x783ee0 UpdateSoundEngine) can be raised to high.

Pitfall re-confirmed: for GOG `Global::` (cdecl) rows the Steam `ret N` is 0 while GOG param_size is the arg bytes; I accepted Global rows only when the exact per-region delta AND the size (+/-6%) matched, never on the vote alone.
Mapper outputs written: findings/R9_map_*.tsv (contain some known-bad rows, e.g. 0x55bb80 CSWSCreature::SetStealthMode, 0x435720 RenderDrawableSquares, 0x73a380 CExoLocString::Destructor; corrected in the table).
