## 3. Facts a fresh context needs (verified this session)
- **L1 formula/sites:** double `2.3333330154418945` at `.rdata` VA 0x009A7D30 (file offset 0x5A6930 in the vanilla exe, bytes `00 00 00 80 AA AA 02 40`). 7 `FDIV double ptr [0x009a7d30]` (`DC 35 30 7D 9A 00`) at 0x8BACE9 (SetTop), 0x8BADE9 (SetBottom), 0x8BAF6E (dead), 0x8BB6A9 (DialogTop ctor), 0x8BB9A6 (SetReply), 0x8BBC25 (Cinematic ctor), 0x8BC467 (Reset). W/H = shorts at GUI manager +0x6C/+0x6E (copied from `DAT_009f42a4/a8`). Reply panel/bottom edge: `H - max(bar, 100*fs)`, fs = 1+0.5*floor((W-1022)/1024) (0x479AB0). The engine overrides x/y/w of the dialog panel in the ctor/Reset; there is no Override `dialog_p.gui` and the ultrawide generator does not touch it. `0x4113A0` is the GUI draw loop (4:3 pillarbox), NOT the dialogue letterbox.
- **L1 fix constraint:** K1/KMRP fix = write `c = 1.5*W/H` over the double so bar = H/6 (all 7 sites follow), plus reply-panel handling (K1: panel immediates -> `bar-36`, min 100). `c` depends on W/H, so a static byte patch cannot do it unless it patches the 7 FDIV sites with a fixed ratio; a DLL (one write at init, or a detour) is the likely route. SemiTransparentLetterbox (live) only changes alpha at 0x8BAA5E / 0x8BB043 / 0x8BB108 / 0x8BB3C3 (>=0xC0 bytes from every FDIV site).
- **L4 fix:** `FADD double ptr [0x0098c1d8]` (=0.25) at 0x47B232 (`DC 05 D8 C1 98 00`); operand bytes at 0x47B234 `D8 C1 98 00` -> `08 7F 98 00` (0.5 double at 0x987F08). No hook logic needed if KPM can write that code address as a "replace"/simple byte patch (it can: SemiTransparentLetterbox does exactly that with `original_bytes`/`replacement_bytes` and records the file offset).
- **KPM hook file format** (see `Patches/SemiTransparentLetterbox/kotor2-steam-aspyr.hooks.toml`): `[metadata] target_versions = [<sha256 of the exe>]` (Steam K2 vanilla `6A522E71...FFEF`); `[[hooks]] address = 0x..., type = "replace"|"simple"|"detour", original_bytes = [...], replacement_bytes = [...]`; replace hooks get the return jump appended; detours call a DLL function (see `shield_bar_src`, `force_power_hotbar_src` for working examples).
- **Live hooks:** `mods678_research/live_hooks_2026-09-30g.tsv` is the latest snapshot (the other dated files are earlier); re-snapshot before any overlap check (sibling sessions install new patches). Overlap tool: `mods678_research/check_windows.py` (+-8 bytes, no relative branches in stolen bytes).
- **Names/DB:** query `ghidra_knowledge/kotor2_ghidra_knowledge.db` with python sqlite3 (no sqlite3 CLI). Mapper rows are hypotheses: **161 Steam addresses are claimed by two different mapper rows** (lesson in DB; the bridge marks `conflict`). 0x47B500 was corrected to `CAurGUIStringInternal::Draw_2`.
- **2DA:** one parser 0x71C3D0 for text `2DA V2.0` and binary `2DA V2.b` (magic in `CRes2DA::OnResourceServiced` 0x729FD0); 256-byte token buffer ends exactly at the stack cookie; binary path only copies column names to it; data-size u16 is written to a stack local at 0x71C8D2 and never read (benign; pipeline-written override tables have it 0).
